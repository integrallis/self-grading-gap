## Implementation

```python
from typing import List

def maxSum(nums: List[int]) -> int:
    unique_values = set()
    total_sum = 0
    for num in nums:
        if num not in unique_values:
            unique_values.add(num)
            total_sum += num
    return total_sum if total_sum > 0 else max(nums)
```

## Implementation

```python
def maxDifference(s: str) -> int:
    from collections import Counter
    frequencies = Counter(s)
    odd_max = max((freq for freq in frequencies.values() if freq % 2 != 0), default=0)
    even_min = min((freq for freq in frequencies.values() if freq % 2 == 0), default=0)
    return odd_max - even_min
```

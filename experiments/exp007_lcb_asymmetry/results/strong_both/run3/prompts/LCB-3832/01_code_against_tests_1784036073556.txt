## Implementation

```python
from typing import List

def minCosts(cost: List[int]) -> List[int]:
    n = len(cost)
    answer = [0] * n
    if n > 0:
        answer[0] = cost[0]
    for i in range(1, n):
        answer[i] = min(answer[i - 1], cost[i])
    return answer

```

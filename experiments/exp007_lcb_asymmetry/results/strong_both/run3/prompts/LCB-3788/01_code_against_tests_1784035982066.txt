## Implementation

```python
from typing import List

def maxSum(nums: List[int]) -> int:
    unique_nums = set()
    max_sum = 0
    for num in nums:
        if num > 0:
            unique_nums.add(num)
    return sum(unique_nums) if unique_nums else max(nums)
```

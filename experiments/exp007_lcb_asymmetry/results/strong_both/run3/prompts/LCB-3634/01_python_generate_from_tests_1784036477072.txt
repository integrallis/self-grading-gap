If no such index j exists for the index i, move on to the next index without making any changes.

Return the total score at the end of the process.

```python
def calculateScore(s: str) -> int:
    score = 0
    mirror = {chr(i): chr(219 - i) for i in range(97, 123)}  # a-z to z-a mapping
    available_indices = {char: [] for char in mirror.keys()}

    for i, char in enumerate(s):
        if available_indices[mirror[char]]:
            j = available_indices[mirror[char]].pop()  # get the closest unmarked mirror index
            score += i - j  # calculate score
        available_indices[char].append(i)  # mark the current index for its character

    return score
```

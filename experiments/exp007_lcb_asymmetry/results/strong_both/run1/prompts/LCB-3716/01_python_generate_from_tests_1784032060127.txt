You are given an array of integers nums.
Your task is to find the length of the longest subsequence seq of nums, such that the absolute differences between consecutive elements form a non-increasing sequence of integers. In other words, for a subsequence seq_0, seq_1, seq_2, ..., seq_m of nums, |seq_1 - seq_0| >= |seq_2 - seq_1| >= ... >= |seq_m - seq_m - 1|.
Return the length of such a subsequence.
A subsequence is an non-empty array that can be derived from another array by deleting some or no elements without changing the order of the remaining elements.

The longest subsequence is [16, 6, 3] with the absolute adjacent differences [10, 3].

```python
from typing import List

def longestSubsequence(nums: List[int]) -> int:
    n = len(nums)
    if n < 2:
        return n

    # Initialize a list to store the maximum length of subsequence ending at each index with their last differences
    states = [{} for _ in range(n)]

    # Iterate through the nums array to fill the states array
    for i in range(n):
        for j in range(i):
            # Calculate the absolute difference
            d = abs(nums[i] - nums[j])
            best = 2  # At least nums[j] and nums[i] can form a subsequence
            # Extend the states based on the valid subsequences ending at j
            for previous_d, length in states[j].items():
                if previous_d >= d:
                    best = max(best, length + 1)
            states[i][d] = max(states[i].get(d, 0), best)

    return max((max(state.values()) for state in states), default=1)
```

## Implementation

```python
from typing import List

def maxSum(nums: List[int]) -> int:
    unique_elements = set(nums)
    positives = [x for x in unique_elements if x > 0]
    if positives:
        return sum(positives)
    return 0 if 0 in unique_elements else max(unique_elements)
```

## Implementation

```python
from typing import List

def maxSum(nums: List[int]) -> int:
    unique_nums = set()
    for num in nums:
        unique_nums.add(num)
    max_sum = sum(unique_nums)
    return max_sum if max_sum > 0 else max(nums) if nums else 0
```

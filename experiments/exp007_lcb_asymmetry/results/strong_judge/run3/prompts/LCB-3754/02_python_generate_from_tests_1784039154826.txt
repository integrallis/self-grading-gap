```python
def maxDistance(s: str, k: int) -> int:
    # Track the count of movements in each direction
    n_count = s.count('N')
    s_count = s.count('S')
    e_count = s.count('E')
    w_count = s.count('W')

    # Calculate the net vertical and horizontal distance
    vertical_distance = n_count - s_count
    horizontal_distance = e_count - w_count

    # Calculate the current Manhattan distance
    current_distance = abs(vertical_distance) + abs(horizontal_distance)

    # The maximum possible distance we can achieve after at most k changes
    # We can change any movement to any other movement, effectively changing the net distance
    # Each change can potentially increase the distance by 1
    max_possible_distance = current_distance + k

    return max_possible_distance
```

## Implementation

```python
from collections import Counter

def maxDifference(s: str) -> int:
    freq = Counter(s)
    max_odd = max((count for count in freq.values() if count % 2 == 1), default=0)
    min_even = min((count for count in freq.values() if count % 2 == 0), default=0)
    return max_odd - min_even
```

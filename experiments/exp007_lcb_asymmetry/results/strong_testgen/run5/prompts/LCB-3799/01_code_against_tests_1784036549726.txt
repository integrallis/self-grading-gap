## Implementation

```python
from typing import List
from itertools import permutations

def totalNumbers(digits: List[int]) -> int:
    even_numbers = set()
    for perm in permutations(digits, 3):
        if perm[0] != 0 and perm[2] % 2 == 0:
            even_numbers.add(perm)
    return len(even_numbers)
```

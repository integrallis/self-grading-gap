There are an infinite amount of bags on a number line, one bag for each coordinate. Some of these bags contain coins.
You are given a 2D array coins, where coins[i] = [l_i, r_i, c_i] denotes that every bag from l_i to r_i contains c_i coins.
The segments that coins contain are non-overlapping.
You are also given an integer k.
Return the maximum amount of coins you can obtain by collecting k consecutive bags.
 
Example 1:

Input: coins = [[8,10,1],[1,3,2],[5,6,4]], k = 4
Output: 10
Explanation:
Selecting bags at positions [3, 4, 5, 6] gives the maximum number of coins: 2 + 0 + 4 + 4 = 10.

Example 2:

Input: coins = [[1,10,3]], k = 2
Output: 6
Explanation:
Selecting bags at positions [1, 2] gives the maximum number of coins: 3 + 3 = 6.

 
Constraints:

1 <= coins.length <= 10^5
1 <= k <= 10^9
coins[i] == [l_i, r_i, c_i]
1 <= l_i <= r_i <= 10^9
1 <= c_i <= 1000
The given segments are non-overlapping.

```python
from typing import List


def maximumCoins(coins: List[List[int]], k: int) -> int:
    # Create a dictionary to hold coins at each position
    coin_map = {}
    
    # Populate the coin_map with the number of coins at each position
    for l, r, c in coins:
        for position in range(l, r + 1):
            coin_map[position] = coin_map.get(position, 0) + c

    # Calculate the maximum coins we can get from k consecutive bags
    max_coins = 0
    current_coins = 0
    start_position = min(coin_map.keys())
    end_position = start_position + k - 1
    
    # Calculate initial sum for the first k positions
    for position in range(start_position, end_position + 1):
        current_coins += coin_map.get(position, 0)
    max_coins = current_coins
    
    # Slide the window across the positions
    while end_position in coin_map or (end_position - start_position + 1) <= k:
        # Move the window one position to the right
        current_coins -= coin_map.get(start_position, 0)
        start_position += 1
        end_position += 1
        current_coins += coin_map.get(end_position, 0)
        max_coins = max(max_coins, current_coins)

    return max_coins
```

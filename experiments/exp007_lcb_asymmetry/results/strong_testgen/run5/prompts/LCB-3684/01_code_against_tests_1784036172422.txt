## Implementation

```python
def hasMatch(s: str, p: str) -> bool:
    prefix, _, suffix = p.partition('*')
    return any(s[i:i + len(prefix) + len(suffix)] == prefix + s[i + len(prefix):i + len(prefix) + len(suffix)] for i in range(len(s) - len(prefix) - len(suffix) + 1))
```

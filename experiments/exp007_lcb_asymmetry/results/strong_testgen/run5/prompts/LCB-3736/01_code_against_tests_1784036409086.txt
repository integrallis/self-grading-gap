## Implementation

```python
def findValidPair(s: str) -> str:
    from collections import Counter
    counts = Counter(s)

    for i in range(len(s) - 1):
        if s[i] != s[i + 1]:
            if counts[s[i]] == int(s[i]) and counts[s[i + 1]] == int(s[i + 1]):
                return s[i] + s[i + 1]
    return ""
```

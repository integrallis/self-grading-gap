## Implementation

```python
def maxDifference(s: str) -> int:
    from collections import Counter
    freq = Counter(s)
    odd_freqs = [count for count in freq.values() if count % 2 == 1]
    even_freqs = [count for count in freq.values() if count % 2 == 0]
    max_odd = max(odd_freqs) if odd_freqs else 0
    min_even = min(even_freqs) if even_freqs else 0
    return max_odd - min_even

```

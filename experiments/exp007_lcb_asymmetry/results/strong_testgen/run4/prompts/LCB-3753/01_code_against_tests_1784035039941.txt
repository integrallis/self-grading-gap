## Implementation

```python
from collections import Counter

def maxDifference(s: str) -> int:
    frequencies = Counter(s)
    odd_freqs = [freq for freq in frequencies.values() if freq % 2 == 1]
    even_freqs = [freq for freq in frequencies.values() if freq % 2 == 0]
    max_odd = max(odd_freqs)
    min_even = min(even_freqs)
    return max_odd - min_even

```

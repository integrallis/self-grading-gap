## Implementation

```python
from typing import List

def minCosts(cost: List[int]) -> List[int]:
    n = len(cost)
    answer = [0] * n
    current_min = float('inf')
    for i in range(n):
        current_min = min(current_min, cost[i])
        answer[i] = current_min
    return answer

```

## Implementation

```python
def countPartitions(nums: List[int]) -> int:
    total_sum = sum(nums)
    n = len(nums)
    # If total sum is even, all n-1 partitions are valid.
    if total_sum % 2 == 0:
        return n - 1
    # If total sum is odd, no partitions are valid.
    return 0
```

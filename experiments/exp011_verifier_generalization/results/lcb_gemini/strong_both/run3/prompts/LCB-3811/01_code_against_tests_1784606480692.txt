## Implementation

```python
def reverseDegree(s: str) -> int:
    total = 0
    for index, char in enumerate(s):
        reversed_alphabet_value = 26 - (ord(char) - ord('a'))
        total += (index + 1) * reversed_alphabet_value
    return total
```

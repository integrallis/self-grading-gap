### Root Cause Analysis

All three failing tests (`test_canonical_example_3`, `test_threshold_forces_higher_weight_solution`, `test_multiple_edges_between_nodes`) fail for the same underlying reason. The `is_possible(max_weight)` helper function is implemented incorrectly.

The task requires finding if there exists a **subgraph** of the available edges (those with weight `≤ max_weight`) that satisfies both the reachability and out-degree constraints. The current implementation does not search for such a subgraph. Instead, it considers the **entire set** of available edges and checks if that complete set satisfies the constraints.

Specifically, in the `is_possible` function:
1.  It correctly identifies the set of `candidate_edges`.
2.  It correctly checks if all nodes can reach node 0 *using all candidate edges*.
3.  It then checks if the out-degree of every node is within the `threshold` *using all candidate edges*.

This approach is flawed. If including all candidate edges causes a node's out-degree to exceed the threshold, the function incorrectly returns `False`, even if a valid subgraph could be formed by omitting some of those edges while still maintaining reachability.

    def is_possible(max_weight: int) -> bool:
        candidate_edges = [e for e in edges if e[2] <= max_weight]
        
        rev_adj = [[] for _ in range(n)]
        for u, v, _ in candidate_edges:
            rev_adj[v].append(u)

        # Backward search from node 0 to find a valid subgraph.
        q = [0]
        has_path = [False] * n
        has_path[0] = True
        
        # Tracks out-degrees in the chosen subgraph.
        out_degree = [0] * n
        
        head = 0
        while head < len(q):
            curr = q[head]
            head += 1
            
            for neighbor in rev_adj[curr]:
                # The edge is (neighbor, curr).
                # If neighbor `u` can be connected and has available out-degree capacity:
                if not has_path[neighbor] and out_degree[neighbor] < threshold:
                    # Select edge (neighbor, curr) for neighbor's path.
                    out_degree[neighbor] += 1
                    has_path[neighbor] = True
                    q.append(neighbor)

        # Check if a path to 0 was found for all nodes.
        return all(has_path)

## Implementation

```python
from typing import List

def zigzagTraversal(grid: List[List[int]]) -> List[int]:
    result = []
    for i in range(len(grid)):
        if i % 2 == 0:
            result.extend(grid[i])  # Traverse right in even rows
        else:
            result.extend(grid[i][::-1])  # Traverse left in odd rows
    return [result[j] for j in range(len(result)) if j % 2 == 0]  # Skip every alternate element
```

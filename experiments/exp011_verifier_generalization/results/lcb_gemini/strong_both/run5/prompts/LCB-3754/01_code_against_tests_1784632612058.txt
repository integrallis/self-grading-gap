```python
def maxDistance(s: str, k: int) -> int:
    x, y = 0, 0
    max_distance = 0
    for char in s:
        if char == 'N':
            y += 1
        elif char == 'S':
            y -= 1
        elif char == 'E':
            x += 1
        elif char == 'W':
            x -= 1
        # Calculate current distance
        current_distance = abs(x) + abs(y)
        max_distance = max(max_distance, current_distance)
        # Use up to k changes to increase distance
        if k > 0:
            # Since we can change any move, we consider the effect of changing the last move
            # For each move, we can think of it as if we can increase the distance by 2 (to go to the opposite direction)
            max_distance = max(max_distance, current_distance + min(k, 2))
    return max_distance
```

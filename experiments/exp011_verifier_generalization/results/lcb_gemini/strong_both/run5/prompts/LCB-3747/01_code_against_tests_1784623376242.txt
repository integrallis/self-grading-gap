## Implementation

```python
from typing import List

def maxAdjacentDistance(nums: List[int]) -> int:
    max_distance = 0
    length = len(nums)
    for i in range(length):
        next_index = (i + 1) % length
        distance = abs(nums[i] - nums[next_index])
        if distance > max_distance:
            max_distance = distance
    return max_distance

```

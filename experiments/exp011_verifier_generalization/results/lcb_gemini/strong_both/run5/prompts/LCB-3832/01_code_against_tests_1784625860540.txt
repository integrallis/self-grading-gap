## Implementation

```python
from typing import List

def minCosts(cost: List[int]) -> List[int]:
    n = len(cost)
    answer = [0] * n
    min_cost = float('inf')
    for i in range(n):
        min_cost = min(min_cost, cost[i])
        answer[i] = min_cost
    return answer

```

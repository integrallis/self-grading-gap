## Implementation

```python
from typing import List

def maxSum(nums: List[int]) -> int:
    unique_elements = set(nums)  # Get unique elements
    positive_sum = sum(x for x in unique_elements if x > 0)  # Sum positive unique elements
    if positive_sum > 0:
        return positive_sum  # Return if there are positive sums
    return max(unique_elements)  # Return the largest unique element if no positives exist
```

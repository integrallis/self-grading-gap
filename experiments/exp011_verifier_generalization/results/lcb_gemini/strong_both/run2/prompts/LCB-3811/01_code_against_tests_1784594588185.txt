## Implementation

```python
def reverseDegree(s: str) -> int:
    total = 0
    for index, char in enumerate(s):
        reverse_alphabet_value = 26 - (ord(char) - ord('a'))
        total += reverse_alphabet_value * (index + 1)
    return total

```

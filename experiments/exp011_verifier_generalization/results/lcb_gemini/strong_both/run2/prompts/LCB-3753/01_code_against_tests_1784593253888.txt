## Implementation

```python
def maxDifference(s: str) -> int:
    from collections import Counter
    frequency = Counter(s)
    odd_freqs = [count for count in frequency.values() if count % 2 != 0]
    even_freqs = [count for count in frequency.values() if count % 2 == 0]
    return max(odd_freqs) - min(even_freqs)
```

# Note for the implementer:
# The problem statement can be interpreted as finding the maximum sum of a
# subset of the unique elements in the input list `nums`. This is because any
# such subset can be chosen, and a modified list can be conceptually formed
# (by deleting other elements) where this chosen subset becomes a contiguous
# subarray. To maximize the sum, we should sum all unique positive numbers. If
# there are no unique positive numbers, the problem requires a non-empty
# selection, so we must select the largest number available (which will be 0 or
# negative). The tests below are based on this logic, which is consistent
# with all provided examples.

def test_canonical_example_1():
    """
    Test case from the problem description, Example 1.
    """
    # spec: maxSum([1,2,3,4,5]) -> 15
    # The array contains only unique positive numbers.
    # The maximum sum is the sum of all elements.
    # 1 + 2 + 3 + 4 + 5 = 15.
    assert maxSum([1, 2, 3, 4, 5]) == 15

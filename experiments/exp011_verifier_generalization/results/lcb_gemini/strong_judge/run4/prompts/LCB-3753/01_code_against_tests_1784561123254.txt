## Implementation

```python
def maxDifference(s: str) -> int:
    from collections import Counter
    frequencies = Counter(s)
    odd_freq = [freq for freq in frequencies.values() if freq % 2 != 0]
    even_freq = [freq for freq in frequencies.values() if freq % 2 == 0]
    if not odd_freq or not even_freq:
        return 0
    return max(odd_freq) - min(even_freq)
```

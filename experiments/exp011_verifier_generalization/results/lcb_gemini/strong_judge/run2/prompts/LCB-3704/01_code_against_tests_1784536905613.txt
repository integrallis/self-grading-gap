## Implementation

```python
from typing import List

def countPartitions(nums: List[int]) -> int:
    total_sum = sum(nums)
    n = len(nums)
    # If the total sum is odd, all partitions will result in an odd difference
    if total_sum % 2 != 0:
        return 0
    # If the total sum is even, all n-1 partitions are valid
    return n - 1
```

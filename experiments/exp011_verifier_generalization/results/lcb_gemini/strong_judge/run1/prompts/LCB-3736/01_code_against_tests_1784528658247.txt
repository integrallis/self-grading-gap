## Implementation

```python
from collections import Counter

def findValidPair(s: str) -> str:
    count = Counter(s)
    for i in range(len(s) - 1):
        if s[i] != s[i + 1]:
            if count[s[i]] == int(s[i]) and count[s[i + 1]] == int(s[i + 1]):
                return s[i] + s[i + 1]
    return ""
```

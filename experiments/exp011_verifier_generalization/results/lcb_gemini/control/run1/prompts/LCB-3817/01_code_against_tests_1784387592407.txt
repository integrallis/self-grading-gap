## Implementation

```python
from typing import List

def maxContainers(n: int, w: int, maxWeight: int) -> int:
    total_cells = n * n
    max_possible_containers = total_cells
    max_weight_with_all = total_cells * w
    if max_weight_with_all <= maxWeight:
        return max_possible_containers
    return maxWeight // w
```

```python
def maxDifference(s: str) -> int:
    from collections import Counter
    frequencies = Counter(s)
    odd_freqs = [freq for freq in frequencies.values() if freq % 2 != 0]
    even_freqs = [freq for freq in frequencies.values() if freq % 2 == 0]
    max_odd = max(odd_freqs)
    max_even = max(even_freqs)
    return max_odd - max_even
```

## Implementation

```python
def maxContainers(n: int, w: int, maxWeight: int) -> int:
    # Calculate total cells on the deck
    total_cells = n * n
    # Calculate the maximum number of containers that can be loaded based on weight
    max_containers_by_weight = maxWeight // w
    # The result is the minimum of available cells and the maximum containers by weight
    return min(total_cells, max_containers_by_weight)
```

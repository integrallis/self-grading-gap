## Implementation

```python
def findValidPair(s: str) -> str:
    from collections import Counter
    count = Counter(s)
    for i in range(len(s) - 1):
        if s[i] != s[i + 1]:
            a, b = int(s[i]), int(s[i + 1])
            if count[s[i]] == a and count[s[i + 1]] == b:
                return s[i] + s[i + 1]
    return ""

```

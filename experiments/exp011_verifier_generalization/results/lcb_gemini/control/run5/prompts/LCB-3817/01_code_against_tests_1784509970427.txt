## Implementation

```python
def maxContainers(n: int, w: int, maxWeight: int) -> int:
    # Calculate the total number of cells on the deck
    total_cells = n * n
    # Calculate the maximum number of containers based on weight capacity
    max_containers_by_weight = maxWeight // w
    # The result is the minimum between total cells and maximum containers by weight
    return min(total_cells, max_containers_by_weight)
```

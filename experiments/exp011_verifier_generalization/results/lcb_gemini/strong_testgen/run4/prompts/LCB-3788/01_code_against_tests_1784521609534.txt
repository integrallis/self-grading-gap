## Implementation

```python
from typing import List

def maxSum(nums: List[int]) -> int:
    seen = set()
    max_sum = float('-inf')
    total_sum = 0

    for num in nums:
        if num > 0 and num not in seen:
            seen.add(num)
            total_sum += num

    return total_sum if total_sum > 0 else max(seen) if seen else 0
```

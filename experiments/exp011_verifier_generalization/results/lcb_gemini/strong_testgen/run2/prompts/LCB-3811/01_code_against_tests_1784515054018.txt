## Implementation

```python
def reverseDegree(s: str) -> int:
    total = 0
    for i, char in enumerate(s):
        reverse_alphabet_value = 26 - (ord(char) - ord('a'))
        total += reverse_alphabet_value * (i + 1)
    return total
```

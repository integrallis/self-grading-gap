## Implementation

```python
def hasMatch(s: str, p: str) -> bool:
    star_index = p.index('*')
    prefix = p[:star_index]
    suffix = p[star_index + 1:]

    for i in range(len(s) - len(prefix) - len(suffix) + 1):
        if s.startswith(prefix, i):
            if s.find(suffix, i + len(prefix)) != -1:
                return True
    return False

```

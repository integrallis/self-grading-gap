## Implementation

```python
from collections import Counter

def maxDifference(s: str) -> int:
    freq = Counter(s)
    odd_freq = [count for count in freq.values() if count % 2 == 1]
    even_freq = [count for count in freq.values() if count % 2 == 0]
    max_odd_freq = max(odd_freq)
    min_even_freq = min(even_freq)
    return max_odd_freq - min_even_freq
```

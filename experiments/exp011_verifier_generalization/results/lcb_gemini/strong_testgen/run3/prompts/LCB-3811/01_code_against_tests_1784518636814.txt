## Implementation

```python
def reverseDegree(s: str) -> int:
    total = 0
    for index, char in enumerate(s):
        position_in_reversed_alphabet = 26 - (ord(char) - ord('a'))
        total += position_in_reversed_alphabet * (index + 1)
    return total

```

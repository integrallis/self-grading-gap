You can reschedule at most k meetings by moving their start time while maintaining the same duration, to maximize the longest continuous period of free time during the event.
The relative order of all the meetings should stay the same and they should remain non-overlapping.
Return the maximum amount of free time possible after rearranging the meetings.
Note that the meetings can not be rescheduled to a time outside the event.

Example 3:

Input: eventTime = 5, k = 2, startTime = [0,1,2,3,4], endTime = [1,2,3,4,5]
Output: 0
Explanation:
There is no time during the event not occupied by meetings.

2 <= n <= 10^5

# Helper function to calculate expected result based on the sliding window on gaps model
def _calculate_expected(eventTime: int, k: int, startTime: List[int], endTime: List[int]) -> int:
    n = len(startTime)
    if n == 0:
        return eventTime
        
    gaps = []
    # Gap at the beginning of the event
    gaps.append(startTime[0])
    # Gaps between meetings
    for i in range(1, n):
        gaps.append(startTime[i] - endTime[i-1])
    # Gap at the end of the event
    gaps.append(eventTime - endTime[n-1])

    window_size = k + 1
    if window_size > len(gaps):
        window_size = len(gaps)

    current_sum = sum(gaps[0:window_size])
    max_sum = current_sum

    for i in range(window_size, len(gaps)):
        current_sum += gaps[i] - gaps[i - window_size]
        if current_sum > max_sum:
            max_sum = current_sum
            
    return max_sum

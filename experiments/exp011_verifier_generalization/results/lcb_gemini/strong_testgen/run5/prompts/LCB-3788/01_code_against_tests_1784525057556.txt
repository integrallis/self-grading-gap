## Implementation

```python
from typing import List

def maxSum(nums: List[int]) -> int:
    unique_nums = set(nums)  # Create a set of unique numbers
    positive_sum = sum(x for x in unique_nums if x > 0)  # Sum only positive unique numbers
    return positive_sum if positive_sum > 0 else max(unique_nums)  # Return the maximum sum or the largest unique number if all are non-positive
```

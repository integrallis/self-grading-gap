## Implementation

```python
def reverseDegree(s: str) -> int:
    reverse_alpha_position = {chr(i): 26 - (i - 97) for i in range(97, 123)}
    return sum(reverse_alpha_position[char] * (index + 1) for index, char in enumerate(s))
```

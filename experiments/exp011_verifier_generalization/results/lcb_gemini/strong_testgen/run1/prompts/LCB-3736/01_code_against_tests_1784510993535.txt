## Implementation

```python
from collections import Counter

def findValidPair(s: str) -> str:
    counts = Counter(s)
    for i in range(len(s) - 1):
        a, b = s[i], s[i + 1]
        if a != b and counts[a] == int(a) and counts[b] == int(b):
            return a + b
    return ""
```

## Implementation

```python
def maxDifference(s: str) -> int:
    from collections import Counter
    frequencies = Counter(s)
    max_odd = max((freq for freq in frequencies.values() if freq % 2 != 0), default=0)
    min_even = min((freq for freq in frequencies.values() if freq % 2 == 0), default=0)
    return max_odd - min_even

```

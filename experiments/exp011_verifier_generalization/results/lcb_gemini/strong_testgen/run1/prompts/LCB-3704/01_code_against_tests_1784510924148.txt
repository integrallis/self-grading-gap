## Implementation

```python
from typing import List

def countPartitions(nums: List[int]) -> int:
    n = len(nums)
    left_sum = 0
    total_sum = sum(nums)
    count = 0

    for i in range(n - 1):
        left_sum += nums[i]
        right_sum = total_sum - left_sum
        if (left_sum - right_sum) % 2 == 0:
            count += 1

    return count

```

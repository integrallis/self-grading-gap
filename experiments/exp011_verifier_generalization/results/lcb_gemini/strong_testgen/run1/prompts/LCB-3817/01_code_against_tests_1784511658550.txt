## Implementation

```python
def maxContainers(n: int, w: int, maxWeight: int) -> int:
    deck_capacity = n * n  # Total cells on the deck
    weight_capacity = maxWeight // w  # Maximum number of containers based on weight
    return min(deck_capacity, weight_capacity)  # Return the limiting factor
```

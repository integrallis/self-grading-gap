There are an infinite amount of bags on a number line, one bag for each coordinate. Some of these bags contain coins.
You are given a 2D array coins, where coins[i] = [l_i, r_i, c_i] denotes that every bag from l_i to r_i contains c_i coins.
The segments that coins contain are non-overlapping.
You are also given an integer k.
Return the maximum amount of coins you can obtain by collecting k consecutive bags.
 
Example 1:

Input: coins = [[8,10,1],[1,3,2],[5,6,4]], k = 4
Output: 10
Explanation:
Selecting bags at positions [3, 4, 5, 6] gives the maximum number of coins: 2 + 0 + 4 + 4 = 10.

Example 2:

Input: coins = [[1,10,3]], k = 2
Output: 6
Explanation:
Selecting bags at positions [1, 2] gives the maximum number of coins: 3 + 3 = 6.

 
Constraints:

1 <= coins.length <= 10^5
1 <= k <= 10^9
coins[i] == [l_i, r_i, c_i]
1 <= l_i <= r_i <= 10^9
1 <= c_i <= 1000
The given segments are non-overlapping.

```python
from typing import List
```

```python
def maximumCoins(coins: List[List[int]], k: int) -> int:
    # Initialize a map to store coins in each bag position
    bags = {}
    
    # Fill the bags map from the input
    for l, r, c in coins:
        for i in range(l, r + 1):
            bags[i] = bags.get(i, 0) + c
    
    # Create a list of all bag positions and their coin counts
    positions = sorted(bags.keys())
    coins_in_bags = [bags[pos] for pos in positions]
    
    # Use a sliding window to find the maximum coins in k consecutive bags
    max_coins = 0
    current_coins = 0
    left = 0
    for right in range(len(positions)):
        current_coins += coins_in_bags[right]
        # If we have more than k bags, slide the window from the left
        if right - left + 1 > k:
            current_coins -= coins_in_bags[left]
            left += 1
        # Update max_coins if we have exactly k bags
        if right - left + 1 == k:
            max_coins = max(max_coins, current_coins)
    
    return max_coins
```

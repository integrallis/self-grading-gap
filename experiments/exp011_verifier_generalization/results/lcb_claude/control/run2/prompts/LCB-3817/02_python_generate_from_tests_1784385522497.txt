def maxContainers(n: int, w: int, maxWeight: int) -> int:
    # Calculate the total number of cells on the deck
    total_cells = n * n
    # Calculate the maximum number of containers that can be loaded based on the weight limit
    max_by_weight = maxWeight // w
    # The result is the minimum of total cells and the maximum by weight
    return min(total_cells, max_by_weight)
```

You are given a 2D array coins, where coins[i] = [l_i, r_i, c_i] denotes that every bag from l_i to r_i contains c_i coins.
The segments that coins contain are non-overlapping.
You are also given an integer k.
Return the maximum amount of coins you can obtain by collecting k consecutive bags.
 
Example 1:

Input: coins = [[8,10,1],[1,3,2],[5,6,4]], k = 4
Output: 10
Explanation:
Selecting bags at positions [3, 4, 5, 6] gives the maximum number of coins: 2 + 0 + 4 + 4 = 10.

Example 2:

Input: coins = [[1,10,3]], k = 2
Output: 6
Explanation:
Selecting bags at positions [1, 2] gives the maximum number of coins: 3 + 3 = 6.

 
Constraints:

1 <= coins.length <= 10^5
1 <= k <= 10^9
coins[i] == [l_i, r_i, c_i]
1 <= l_i <= r_i <= 10^9
1 <= c_i <= 1000
The given segments are non-overlapping.

```python
from typing import List
```


```python
def maximumCoins(coins: List[List[int]], k: int) -> int:
    # Create a dictionary to hold the number of coins available at each bag position
    coin_map = {}

    # Fill the coin_map with the number of coins from each segment
    for l, r, c in coins:
        for pos in range(l, r + 1):
            coin_map[pos] = coin_map.get(pos, 0) + c

    # Sort the positions to compute the maximum coins over k consecutive bags
    sorted_positions = sorted(coin_map.keys())
    max_coins = 0
    current_sum = 0
    left = 0

    # Using a sliding window approach to find the maximum sum of coins in k consecutive bags
    for right in range(len(sorted_positions)):
        current_sum += coin_map[sorted_positions[right]]

        # If we reach more than k bags, slide the window
        if right - left + 1 > k:
            current_sum -= coin_map[sorted_positions[left]]
            left += 1

        # Update max_coins if we have exactly k bags
        if right - left + 1 == k:
            max_coins = max(max_coins, current_sum)

    return max_coins

```

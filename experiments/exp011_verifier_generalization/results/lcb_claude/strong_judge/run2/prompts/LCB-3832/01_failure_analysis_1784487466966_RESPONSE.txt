### test_canonical_example_1

**Input:** `[5, 3, 4, 1, 3, 2]`  
**Expected:** `[5, 3, 3, 1, 1, 1]`  
**Got:** `[1, 1, 1, 1, 1, 1]`

**Trace:**
- `n = 6`
- `global_min = min([5, 3, 4, 1, 3, 2]) = 1`
- `answer[0] = global_min = 1` ← **First divergence: should be 5**
- `answer[1] = min(answer[0], cost[1]) = min(1, 3) = 1` ← should be 3
- `answer[2] = min(answer[1], cost[2]) = min(1, 4) = 1` ← should be 3
- `answer[3] = min(answer[2], cost[3]) = min(1, 1) = 1` ← correct
- `answer[4] = min(answer[3], cost[4]) = min(1, 3) = 1` ← correct
- `answer[5] = min(answer[4], cost[5]) = min(1, 2) = 1` ← correct

**Root cause:** Line `answer[0] = global_min` is incorrect. The problem requires that `answer[0]` should be `cost[0]` (the cost at position 0 itself), not the global minimum of the entire array. The position 0 has no previous positions to swap with, so the minimum cost to reach position 0 is simply `cost[0]`.

The implementation incorrectly assumes that position 0 should have the global minimum cost, but position 0 can only use its own cost since there are no earlier positions to leverage. The minimum cost to reach each position `i` should be the minimum of:
- `cost[i]` (use position i's own cost)
- `answer[i-1]` (the minimum cost to reach the previous position, which allows free swaps from there)

For position 0, there is no previous position, so it must be `cost[0]`.

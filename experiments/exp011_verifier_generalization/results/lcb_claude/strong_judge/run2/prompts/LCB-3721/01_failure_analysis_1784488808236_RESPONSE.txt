**test_canonical_example_1** — expected [2, 2], crashed with `ValueError: invalid literal for int() with base 10: ''`
Input: `numberOfUsers=2, events=[["MESSAGE","10","id1 id0"],["OFFLINE","11","0"],["MESSAGE","71","HERE"]]`

## Root Cause

All failures stem from a single mechanical issue: the implementation assumes OFFLINE events contain user IDs in the format `"id<num>"` (e.g., `"id0"`), but the test data shows OFFLINE events use plain integer strings (e.g., `"0"`). The code at line 14 incorrectly tries to extract the numeric part by slicing off the first two characters (`[2:]`), which works for `"id0"` → `"0"` but fails for `"0"` → `""`.

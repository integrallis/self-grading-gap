```python
def maxDistance(s: str, k: int) -> int:
    x, y = 0, 0
    max_distance = 0
    for direction in s:
        if direction == 'N':
            y += 1
        elif direction == 'S':
            y -= 1
        elif direction == 'E':
            x += 1
        elif direction == 'W':
            x -= 1
        max_distance = max(max_distance, abs(x) + abs(y))
    
    # If we are allowed to change k movements, we can increase the maximum distance
    # by 'k' units. The maximum distance is obtained by moving away from the origin
    # in a straight direction after utilizing the allowed changes.
    return max_distance + k
```

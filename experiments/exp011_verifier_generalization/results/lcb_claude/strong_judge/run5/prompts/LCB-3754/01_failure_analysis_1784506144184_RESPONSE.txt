## Root Cause

All three failures stem from the same algorithmic flaw: **the line `return max_distance + k` incorrectly assumes that k changes always add exactly k units to the observed maximum distance**. This is fundamentally wrong because:

1. Changes can prevent backtracking (avoiding moves that reduce distance), not just extend distance
2. The optimal use of k changes depends on the entire path structure, not just the maximum distance achieved without changes
3. The maximum achievable distance with k changes may require strategically replacing moves at any point in the sequence

The problem requires finding which k moves to change (and to what direction) to maximize the distance from origin at any point during the traversal, not simply adding k to the baseline maximum.

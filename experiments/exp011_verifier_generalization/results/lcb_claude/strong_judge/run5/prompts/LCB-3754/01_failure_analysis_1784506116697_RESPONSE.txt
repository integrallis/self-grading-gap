## Root cause summary

All five failures stem from the same fundamental flaw: **the implementation attempts to compute the maximum distance by first simulating the original path, then adding some adjustment for changes. This approach is wrong because:**
1. The maximum distance during traversal depends on which moves are changed and when those changes are applied in the sequence
2. You cannot simply add "changes" to an already-computed max_distance
3. The problem requires finding the optimal sequence of k substitutions and then computing the maximum distance along that modified path

The correct approach requires either:
- Dynamic programming or search to find which k positions to change and to what directions
- Simulating different possible change strategies and tracking maximum distance during each simulation

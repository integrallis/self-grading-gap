## Root Cause

All four failures stem from the same algorithmic error: the implementation (lines 17-28) incorrectly treats "changing k directions" as adding delta vectors to already-computed positions. The actual problem requires:
1. Choosing which k positions in the original string to modify
2. Choosing what direction to change each to
3. Recomputing the entire path from the start with those changes
4. Finding the maximum Manhattan distance from origin reached during that path
5. Trying all possible combinations to find the global maximum

The current approach of adding `change_effects` to `max_distance` is mathematically nonsensical for this problem.

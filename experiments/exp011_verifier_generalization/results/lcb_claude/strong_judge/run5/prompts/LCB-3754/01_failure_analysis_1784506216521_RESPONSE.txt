## Root Cause Summary

All four failing tests fail for the same reason: **the implementation does not actually change the input string and recompute paths**. Instead, it:
1. Computes the maximum distance for the original unchanged path
2. Generates arbitrary "change effects" by adding direction deltas to already-visited positions
3. Sums these effects with the original max_distance

This is completely wrong. The problem requires:
1. Selecting which k positions in the input string to change and what to change them to
2. Simulating the entire path with those changes applied
3. Finding the maximum distance reached during that modified path
4. Trying different combinations of changes to find the globally optimal result

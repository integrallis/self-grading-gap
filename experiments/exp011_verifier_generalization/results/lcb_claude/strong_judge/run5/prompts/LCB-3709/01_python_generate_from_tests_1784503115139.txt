```python
def hasSpecialSubstring(s: str, k: int) -> bool:
    n = len(s)
    if k > n:
        return False
    for i in range(n - k + 1):
        substring = s[i:i + k]
        if len(set(substring)) == 1:
            before_diff = (i == 0) or (s[i - 1] != substring[0])
            after_diff = (i + k == n) or (s[i + k] != substring[0])
            if before_diff or after_diff:
                return True
    return False

```

### test_failed_boundaries — expected False, got True

**Inputs:** `s = "aaa"`, `k = 2`

**Expected:** `False`

**Trace:**
- `n = 3`
- Loop iterates `i` from `0` to `1` (range(3 - 2 + 1) = range(2))
- **i = 0:**
  - `substring = s[0:2] = "aa"`
  - `len(set("aa")) == 1` ✓ (homogeneous)
  - `before_diff = (0 == 0) or (s[-1] != "a")` evaluates to `True or ...` → `True`
  - `after_diff = (0 + 2 == 3) or (s[2] != "a")` evaluates to `False or (s[2] != "a")` → `False or ("a" != "a")` → `False or False` → `False`
  - `if True or False:` → `True`, so **returns True**

**Problem identified:**

The condition `if before_diff or after_diff:` uses **OR** logic. This means the function returns `True` if **either** boundary is different (or doesn't exist), not requiring **both** boundaries to be different.

For the substring `"aa"` at position 0 in `"aaa"`:
- Before position 0: no character exists (boundary condition satisfied)
- After position 2: character is `"a"` (same as substring, boundary condition **not** satisfied)

The implementation incorrectly accepts this as valid because one boundary passes. However, the test expects `False` because the substring `"aa"` at position 0 is followed by another `"a"`, making it not truly "special" (it's part of a longer run of the same character).

The correct interpretation from the test is: a special substring must have **both** boundaries either be string boundaries (start/end) **OR** be different characters. When using OR logic, a substring at the very start or very end will always satisfy the condition even if the other boundary fails.

The fix requires changing the logic to **AND**: both boundary conditions must be satisfied simultaneously.

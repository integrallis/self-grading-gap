## Root Cause

The implementation fails when a homogeneous substring is embedded within a longer run of the same character. The boundary check requires *both* before and after positions to differ, but when k < total run length, no position within the run can satisfy both conditions simultaneously (interior positions fail before_diff, and all but the last fail after_diff).

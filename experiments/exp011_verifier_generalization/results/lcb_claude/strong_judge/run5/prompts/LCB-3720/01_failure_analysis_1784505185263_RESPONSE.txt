## Root Cause

All three failing tests share the same fundamental issue: **the BFS explores connectivity in the wrong direction**. The implementation checks which nodes are reachable FROM node 0, but the problem requires checking which nodes can reach TO node 0. Since edges are directed (u→v), and the goal is for every node to have a path TO node 0, the BFS should start from all nodes and check if they can reach 0, OR the graph should be traversed in reverse.

Additionally, there's a second issue: **outgoing_count is counting the wrong thing**. The threshold limits the number of edges going INTO each node (in-degree), but `outgoing_count[v] += 1` is incremented when adding edges to `filtered_graph[v]`, which represents edges FROM v in the reversed representation.

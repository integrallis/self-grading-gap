## Root Cause

All three failures share the same root cause: **the `outgoing_count` is being calculated for the wrong direction**. The implementation reverses the graph for reachability checking (which is correct for checking if all nodes can reach node 0), but then uses this reversed graph to count outgoing edges per node. The threshold constraint applies to the **outgoing** edges from each node in the **original** graph (before reversal), not the outgoing edges in the reversed graph.

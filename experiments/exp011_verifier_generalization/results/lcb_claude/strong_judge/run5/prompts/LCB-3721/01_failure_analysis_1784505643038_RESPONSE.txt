## Root Cause

All six failing tests fail due to the same mechanical error: **OFFLINE events provide user IDs as plain integer strings (e.g., `"0"`, `"1"`) without the "id" prefix, but the implementation assumes they have the "id" prefix and attempts to strip it with `[2:]` slicing at line 14.**

The two passing tests (test_duplicate_mentions and test_single_user) only use MESSAGE events with "id"-prefixed user IDs in the mention strings, so they never execute the problematic OFFLINE parsing code.

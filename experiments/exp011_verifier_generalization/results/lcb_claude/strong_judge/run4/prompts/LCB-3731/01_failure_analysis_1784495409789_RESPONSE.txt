## Analysis

### test_canonical_example_1
**Input:** `[2, 3, 1]`  
**Expected:** `11`  
**Got:** `13`

Tracing the implementation:
- `i=0`: `start = max(0, 0-2) = 0`, subarray `nums[0:1] = [2]`, sum = `2`, total = `2`
- `i=1`: `start = max(0, 1-2) = 0`, subarray `nums[0:2] = [2, 3]`, sum = `5`, total = `7`
- `i=2`: `start = max(0, 2-2) = 0`, subarray `nums[0:3] = [2, 3, 1]`, sum = `6`, total = `13`

But the test expects:
- Index 0: subarray starting at index 0, length 1: `[2]` → sum = `2`
- Index 1: subarray starting at index 0, length 2: `[2, 3]` → sum = `5`
- Index 2: subarray starting at index 1, length 2: `[3, 1]` → sum = `4`
- Total: `2 + 5 + 4 = 11`

**Divergence:** At `i=2`, the implementation computes `nums[0:3] = [2, 3, 1]` (sum=6) but the test expects `nums[1:3] = [3, 1]` (sum=4). The issue is that the implementation uses `max(0, i-2)` which gives start=0 for i=2, creating a subarray of length 3, but the test expects a maximum length of 2 (not 3).

### test_canonical_example_2
**Input:** `[3, 1, 1, 2]`  
**Expected:** `13`  
**Got:** `16`

Tracing the implementation:
- `i=0`: `start = max(0, -2) = 0`, subarray `nums[0:1] = [3]`, sum = `3`, total = `3`
- `i=1`: `start = max(0, -1) = 0`, subarray `nums[0:2] = [3, 1]`, sum = `4`, total = `7`
- `i=2`: `start = max(0, 0) = 0`, subarray `nums[0:3] = [3, 1, 1]`, sum = `5`, total = `12`
- `i=3`: `start = max(0, 1) = 1`, subarray `nums[1:4] = [1, 1, 2]`, sum = `4`, total = `16`

But the test expects:
- Index 0: `[3]` → sum = `3`
- Index 1: `[3, 1]` → sum = `4`
- Index 2: `[1, 1]` → sum = `2`
- Index 3: `[1, 1, 2]` → sum = `4`
- Total: `3 + 4 + 2 + 4 = 13`

**Divergence:** At `i=2`, the implementation computes `nums[0:3] = [3, 1, 1]` (sum=5) but the test expects `nums[1:3] = [1, 1]` (sum=2). Again, the formula `start = max(0, i-2)` allows subarrays of length 3 when the maximum should be 2.

## Root Cause

Both failures stem from the same error: the expression `start = max(0, i - 2)` allows subarrays of length up to 3. When `i=2`, `start=0`, so `nums[0:3]` is a length-3 subarray. The correct formula for a maximum subarray length of 2 should be `start = max(0, i - 1)`, which would give `start=1` at `i=2`, producing `nums[1:3]` (length 2).

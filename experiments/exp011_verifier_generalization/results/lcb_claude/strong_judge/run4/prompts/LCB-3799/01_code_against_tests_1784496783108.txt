## Implementation

```python
from typing import List
from itertools import permutations

def totalNumbers(digits: List[int]) -> int:
    even_numbers = set()
    for last_digit in set(d for d in digits if d % 2 == 0):
        for perm in permutations(digits, 3):
            if perm[2] == last_digit and perm[0] != 0:
                even_numbers.add(perm)
    return len(even_numbers)
```

```python
def hasMatch(s: str, p: str) -> bool:
    star_index = p.index('*')
    prefix = p[:star_index]
    suffix = p[star_index + 1:]
    prefix_length = len(prefix)
    suffix_length = len(suffix)

    for i in range(len(s) - prefix_length - suffix_length + 1):
        if s[i:i + prefix_length] == prefix:
            for j in range(i + prefix_length, len(s) - suffix_length + 1):
                if s[j:j + suffix_length] == suffix:
                    return True
    return False
```

- `suffix = "d"` (characters after `*`)

- Outer loop: `range(len(s) - prefix_length - suffix_length + 1)` = `range(5 - 1 - 1 + 1)` = `range(4)` → `i ∈ {0, 1, 2, 3}`
  
  When `i = 0`:
  - `s[0:1] = "a"` equals `prefix = "a"` ✓
  - Inner loop: `range(i + prefix_length, len(s) - suffix_length + 1)` = `range(1, 5)` → `j ∈ {1, 2, 3, 4}`
    - When `j = 4`: `s[4:5] = "d"` equals `suffix = "d"` ✓
    - Returns `True`

The problem: The implementation treats the pattern as "find prefix anywhere, then find suffix anywhere after that" without requiring that the prefix and suffix be part of the **same contiguous substring**. In "aXcYd" with pattern "a*d", it finds "a" at position 0 and "d" at position 4, but the actual substring from position 0 that starts with "a" is "aXcYd", which does NOT end with "d" — it ends with "d" only because we're looking at the entire rest of the string.

The correct interpretation is: the wildcard `*` should match zero or more characters **between** the prefix and suffix within a single contiguous match. So for "a*d", we need a substring that:
- Starts with "a"
- Ends with "d"  
- The characters between the prefix and suffix should be contiguous

In "aXcYd", if we start at position 0 with "a", the substring must end at some position `j` where `s[j] = "d"`. At position 0, the next "d" is at index 4, giving substring "aXcYd". But "aXcYd" does NOT end with just "d" as the suffix — the suffix check `s[4:5] = "d"` is checking a single character at the END of the string, not whether the substring from `i` to some endpoint actually ends with the suffix.

**Root cause**: Line `if s[j:j + suffix_length] == suffix:` checks if the suffix appears at position `j`, but doesn't verify that position `j` is actually the end of a substring that starts at position `i`. The substring from `i` (where prefix starts) should end exactly at `j + suffix_length`, meaning the full substring is `s[i:j + suffix_length]`, and this should start with prefix and end with suffix.

```python
from typing import List

def maxSum(nums: List[int]) -> int:
    max_sum = float('-inf')
    current_sum = 0
    last_seen = {}
    start = 0

    for i, num in enumerate(nums):
        if num in last_seen and last_seen[num] >= start:
            start = last_seen[num] + 1
        last_seen[num] = i
        current_sum = sum(nums[start:i + 1])
        max_sum = max(max_sum, current_sum)

    return max_sum if max_sum != float('-inf') else 0
```

## Root Cause

Both failures stem from the same algorithmic misunderstanding: **the implementation treats this as a "maximum sum of contiguous subarray without duplicates" problem, but the tests require "maximum sum of any subset with all duplicates of any included value removed."**

The correct interpretation from the tests:
- If you include a value `v` in your sum, you must delete ALL occurrences of `v` first, then sum the remaining unique values you choose
- OR: you can only count each distinct value once, and you pick which distinct values to include to maximize the sum
- From test_canonical_example_2: `[1,1,0,1,1]` → answer is 1, meaning we select only the value `1` (counting it once despite multiple occurrences), not `1+0=1`
- From test_canonical_example_3: `[1,2,-1,-2,1,0,-1]` → answer is 3, meaning we select values `2` and `1` (each counted once), giving `2+1=3`

The problem is actually: **for each distinct value, decide whether to include it (counted once) or not, to maximize the sum**.

Implementation: (1) Get the set of unique values from `nums`, (2) For each unique value, decide to include it or not, (3) Return the maximum sum achievable. The optimal solution is to include all distinct positive values and exclude all distinct non-positive values UNLESS all values are non-positive, in which case include only the maximum value.

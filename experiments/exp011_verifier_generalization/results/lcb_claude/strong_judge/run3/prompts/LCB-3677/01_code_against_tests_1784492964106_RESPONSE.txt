## Root cause

The implementation has a bug in the initialization. When `coins[0][0] >= 0`, it sets `dp[0][0][0] = coins[0][0]` correctly. But when `coins[0][0] < 0`, it only sets `dp[0][0][1] = 0` (neutralizing), leaving `dp[0][0][0] = -inf`. This means paths that don't neutralize the starting cell get `-inf` even though we can choose to take the negative value. The starting cell should always be taken (either as-is or neutralized), so `dp[0][0][0]` should be `coins[0][0]` even if negative.

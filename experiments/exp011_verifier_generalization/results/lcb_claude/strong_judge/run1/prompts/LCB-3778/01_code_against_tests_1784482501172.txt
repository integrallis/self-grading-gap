## Implementation

```python
from typing import List

def transformArray(nums: List[int]) -> List[int]:
    # Replace evens with 0 and odds with 1
    transformed = [0 if num % 2 == 0 else 1 for num in nums]
    # Sort the transformed array
    return sorted(transformed)
```

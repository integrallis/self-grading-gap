## Root Cause

The implementation incorrectly counts contributions. It double-counts each element's contribution as both minimum and maximum across all subsequences, but the logic for determining when an element is the minimum or maximum in a subsequence is flawed. The correct approach requires counting how many subsequences have a specific element as their minimum or maximum, which depends on the relative positions and values, not just combinatorics on sorted positions.

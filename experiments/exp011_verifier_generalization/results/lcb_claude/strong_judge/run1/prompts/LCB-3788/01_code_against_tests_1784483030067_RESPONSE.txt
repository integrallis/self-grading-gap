## Root cause

The implementation initializes `max_sum = 0`, which causes it to fail when all valid subarrays have negative sums. Additionally, it doesn't properly track the maximum sum when unique elements form subarrays - it only updates `max_sum` when a duplicate is encountered, missing the final subarray's sum unless explicitly compared at the end (which happens via `max(max_sum, current_sum)` but fails due to the 0 initialization issue).

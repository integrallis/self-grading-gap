**Expected:** `True` (the substring "abc" matches when star is replaced with "b")

**Root cause:** The algorithm only checks if the **remaining string after the prefix** ends with the suffix. It doesn't check all possible substrings of `s`. The pattern "a*c" should match the substring "abc" within "abcd", but the current logic checks if the **entire tail** of the string after finding "a" ends with "c". 

At position 0, it finds prefix "a", then checks if "bcd" (the remainder) ends with "c" — which it doesn't. The algorithm never considers checking whether there exists some middle portion where we can find both the prefix start and suffix end **within a substring**, rather than requiring the suffix to be at the very end of the string.

The implementation fails to iterate over all possible **substrings** of `s`. Instead, it only iterates over starting positions for the prefix and then requires the suffix to be at the end of the entire remaining string, not at the end of some substring.

**FIX:** Replace the hasMatch implementation logic entirely. The current approach iterates over prefix starting positions but doesn't enumerate all possible substrings. Instead, use a nested loop structure:
- Outer loop: iterate over all possible substring starting positions `i` in range `0` to `len(s)`
- Inner loop: iterate over all possible substring ending positions `j` in range `i+1` to `len(s)+1`
- For each substring `s[i:j]`, check if it matches the pattern by verifying:
  - The substring starts with `prefix`

def hasMatch(s: str, p: str) -> bool:
    star_index = p.index('*')
    prefix = p[:star_index]
    suffix = p[star_index + 1:]
    
    # Check all possible substrings of s
    for i in range(len(s)):
        for j in range(i + 1, len(s) + 1):
            substring = s[i:j]
            if substring.startswith(prefix) and substring.endswith(suffix):
                # Check if the substring is long enough for both prefix and suffix

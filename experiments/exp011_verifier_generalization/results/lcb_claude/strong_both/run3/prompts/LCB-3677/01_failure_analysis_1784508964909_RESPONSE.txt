## Analysis of Failing Tests

**test_single_cell_positive** — expected 5, got 0
- Input: `[[5]]`
- Expected: 5
- The DP array is initialized with `dp[0][0][0] = 0` (before entering the grid)
- For cell (0,0) with value 5: should update `dp[1][1][0]` from transitions coming from `dp[0][1][0]` or `dp[1][0][0]`
- However, `dp[0][1][0]` and `dp[1][0][0]` are both `-inf` (never initialized)
- The only initialized value is `dp[0][0][0] = 0`, but the code never transitions from `dp[0][0][used]` to `dp[1][1][used]`
- The return statement `max(max(dp[m][n]), 0)` tries to find max of `dp[1][1]`, which contains only `-inf` values, then takes max with 0, returning 0

**Root cause identified**: The DP initialization and transition logic is fundamentally flawed. The implementation initializes `dp[0][0][0] = 0` representing a state "before" the grid, but the transitions read from `dp[i][j+1]` (coming from left) and `dp[i+1][j]` (coming from top), which should be `dp[i][j]` instead. The indexing is off by one.

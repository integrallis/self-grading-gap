## Implementation

```python
from typing import List

def maxAdjacentDistance(nums: List[int]) -> int:
    max_distance = 0
    n = len(nums)
    for i in range(n):
        current_distance = abs(nums[i] - nums[(i + 1) % n])
        max_distance = max(max_distance, current_distance)
    return max_distance
```

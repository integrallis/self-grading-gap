## Root Cause Summary

All four failures stem from the same algorithmic error: the greedy extension loop (lines 21-27) incorrectly computes differences from `nums[i]` (a fixed index) when it should compute differences from the **last element added to the subsequence**. Additionally, the skip condition for zero differences (line 20) incorrectly prevents valid subsequences with zero differences.

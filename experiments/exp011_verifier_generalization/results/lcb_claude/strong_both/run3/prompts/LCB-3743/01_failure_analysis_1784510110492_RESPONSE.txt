## Root Cause Summary

All three failures share the same root cause: the implementation assumes that each value of k can only combine two adjacent gaps (by rescheduling the single meeting between them). This is fundamentally incorrect. When k≥n (where n is the number of meetings separating consecutive gaps), we can reschedule all n meetings and combine n+1 gaps together.

The correct approach is: if we have m consecutive gaps and k available reschedulings, we can combine up to min(k+1, m) consecutive gaps by rescheduling the min(k, m-1) meetings that separate them.

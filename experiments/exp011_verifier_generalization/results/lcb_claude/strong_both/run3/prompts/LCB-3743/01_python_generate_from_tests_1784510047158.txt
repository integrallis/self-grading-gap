Full problem statement:

You are given an integer eventTime denoting the duration of an event, where the event occurs from time t = 0 to time t = eventTime.
You are also given two integer arrays startTime and endTime, each of length n. These represent the start and end time of n non-overlapping meetings, where the i^th meeting occurs during the time [startTime[i], endTime[i]].
You can reschedule at most k meetings by moving their start time while maintaining the same duration, to maximize the longest continuous period of free time during the event.
The relative order of all the meetings should stay the same and they should remain non-overlapping.
Return the maximum amount of free time possible after rearranging the meetings.
Note that the meetings can not be rescheduled to a time outside the event.
 
Example 1:

Input: eventTime = 5, k = 1, startTime = [1,3], endTime = [2,5]
Output: 2
Explanation:

Reschedule the meeting at [1, 2] to [2, 3], leaving no meetings during the time [0, 2].

Example 2:

Input: eventTime = 10, k = 1, startTime = [0,2,9], endTime = [1,4,10]
Output: 6
Explanation:

Reschedule the meeting at [2, 4] to [1, 3], leaving no meetings during the time [3, 9].

Example 3:

Input: eventTime = 5, k = 2, startTime = [0,1,2,3,4], endTime = [1,2,3,4,5]
Output: 0
Explanation:
There is no time during the event not occupied by meetings.

 
Constraints:

1 <= eventTime <= 10^9
n == startTime.length == endTime.length
2 <= n <= 10^5
1 <= k <= n
0 <= startTime[i] < endTime[i] <= eventTime
endTime[i] <= startTime[i + 1] where i lies in the range [0, n - 2].

    assert maxFreeTime(10, 2, [2, 6], [4, 8]) == 6

    # eventTime=15, k=1, meetings at [0,3], [5,7], [10,15]

    # Can reschedule middle meeting to create larger gap
    # Move [5,7] to [3,5], leaving [5,10] free -> 5

def test_all_meetings_can_be_rescheduled():
    # eventTime=10, k=3, meetings at [1,2], [3,4], [5,6]
    # All 3 meetings have duration 1, can push all to end
    # [7,8], [8,9], [9,10], leaving [0,7] free -> 7
    assert maxFreeTime(10, 3, [1, 3, 5], [2, 4, 6]) == 7


def test_large_gap_at_start():
    # eventTime=20, k=1, meetings at [10,12], [15,20]
    # Initial gap at start: [0,10]=10, gap between: [12,15]=3
    # Can reschedule first meeting to [12,14], creating [0,12]=12 free, or
    # reschedule first to end right after itself, or reschedule second
    # Best: move [10,12] to [13,15], creating [0,13]=13 free? No, must maintain order.
    # Move [10,12] to [12,14], gap [0,12]=12, then [14,15]=1, then [15,20]=meeting
    # Or move [15,20] earlier? Can't because must maintain order and non-overlap
    # Actually: move first meeting to [13,15], then second stays [15,20]
    # This gives [0,13]=13 free
    assert maxFreeTime(20, 1, [10, 15], [12, 20]) == 13


def test_single_unit_meetings():
    # eventTime=6, k=2, meetings at [0,1], [2,3], [4,5]
    # Each meeting duration 1, gaps: [1,2]=1, [3,4]=1, [5,6]=1
    # Reschedule 2 meetings: move first two to pack together
    # [0,1], [1,2], leaves [4,5] as meeting, and [2,4]=2 free, then [5,6]=1 free
    # Or move last two: [4,5], [5,6], leaves [0,1] as meeting, [1,4]=3 free
    # Best: move middle and last to end: [4,5], [5,6], keep [0,1], gap [1,4]=3
    assert maxFreeTime(6, 2, [0, 2, 4], [1, 3, 5]) == 3

    # Or move second to [1,2], creating [0,1]=meeting and [2,4]=2
    # Maximum is 2
    assert maxFreeTime(4, 1, [0, 3], [1, 4]) == 2


def test_large_event_time():
    # eventTime=10**9, k=1, meetings at [0,100000000] and [500000000,10**9]
    # Duration of first: 100000000, duration of second: 500000000
    # Initial gaps: none at start, [100000000,500000000]=400000000, none at end
    # Reschedule first to [400000000,500000000], creating [0,400000000]=400000000 free
    # Or reschedule second: can't move it earlier significantly without violating order
    # Best: move first meeting to butt against second, creating [0,400000000]=400000000
    assert maxFreeTime(10**9, 1, [0, 500000000], [100000000, 10**9]) == 400000000


def test_large_number_of_meetings():
    # eventTime=200000, n=10**5 (100000 meetings), k=1
    # Each meeting has duration 1, placed at [0,1], [2,3], [4,5], ..., [199998,199999]
    # Initial gaps: [1,2]=1, [3,4]=1, ..., [199997,199998]=1, [199999,200000]=1
    # Total of 100000 meetings means indices 0 to 99999
    # Meeting i at [2*i, 2*i+1]
    # Last meeting at [2*99999, 2*99999+1] = [199998, 199999]
    # Gaps are all of size 1
    # Reschedule one meeting: can combine two consecutive gaps
    # Move meeting at [2*i, 2*i+1] to [2*i+1, 2*i+2], merging gaps [2*i-1,2*i] and [2*i+1,2*i+2]
    # This creates gap of size 2
    n = 100000
    startTime = [2 * i for i in range(n)]
    endTime = [2 * i + 1 for i in range(n)]
    eventTime = 2 * n  # 200000
    # With k=1, we can reschedule one meeting to merge two gaps of size 1 into one gap of size 2
    assert maxFreeTime(eventTime, 1, startTime, endTime) == 2

You start with a score of 0, and you perform the following process on the string s:

Iterate through the string from left to right.
At each index i, find the closest unmarked index j such that j < i and s[j] is the mirror of s[i]. Then, mark both indices i and j, and add the value i - j to the total score.
If no such index j exists for the index i, move on to the next index without making any changes.

Return the total score at the end of the process.

```python
def calculateScore(s: str) -> int:
    score = 0
    marked = set()
    n = len(s)
    for i in range(n):
        mirror_char = chr(219 - ord(s[i]))  # 219 = 'a' + 'z'
        for j in range(i - 1, -1, -1):  # Look for j < i
            if j in marked:
                continue
            if s[j] == mirror_char:
                marked.add(i)
                marked.add(j)
                score += i - j
                break
        marked.add(i)  # Mark i as processed
    return score

```

## Root cause

The implementation has a critical bug: it unconditionally adds `marked.add(i)` at the end of each iteration, even when no match is found. This means every index is marked as soon as it's processed, so when looking backward for unmarked indices with the mirror character, all previous indices are already marked and skipped. The line `marked.add(i)` should only execute when a match is found (inside the `if s[j] == mirror_char:` block along with `marked.add(j)`), not unconditionally.

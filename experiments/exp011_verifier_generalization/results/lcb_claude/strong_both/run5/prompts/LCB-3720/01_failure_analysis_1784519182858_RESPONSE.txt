## Root Cause

The fundamental algorithmic error is in how edges are selected. The implementation performs binary search on the maximum weight and includes ALL edges with weight <= mid. However, this doesn't respect the threshold constraint properly when a node has multiple outgoing edges below the weight limit.

The correct approach is: for each node with more outgoing edges than the threshold allows, we must SELECT which threshold-many edges to keep (choosing the ones with smallest weights to minimize the maximum). The current implementation doesn't do this selection; it just checks if out_degree > threshold and fails.

Specifically, in `bfs_check`, when building the graph from `edge_map`, the code adds ALL edges with `w <= mid` without limiting each node to at most `threshold` outgoing edges. Then it checks `if out > threshold: return False`, which fails when it should instead be selecting the best subset of edges.

There are an infinite amount of bags on a number line, one bag for each coordinate. Some of these bags contain coins.
You are given a 2D array coins, where coins[i] = [l_i, r_i, c_i] denotes that every bag from l_i to r_i contains c_i coins.

You are also given an integer k.
Return the maximum amount of coins you can obtain by collecting k consecutive bags.

Selecting bags at positions [3, 4, 5, 6] gives the maximum number of coins: 2 + 0 + 4 + 4 = 10.

Example 2:

Input: coins = [[1,10,3]], k = 2
Output: 6
Explanation:
Selecting bags at positions [1, 2] gives the maximum number of coins: 3 + 3 = 6.

 
Constraints:

1 <= coins.length <= 10^5
1 <= k <= 10^9
coins[i] == [l_i, r_i, c_i]
1 <= l_i <= r_i <= 10^9
1 <= c_i <= 1000
The given segments are non-overlapping.

```python
from typing import List
```


```python
def maximumCoins(coins: List[List[int]], k: int) -> int:
    # Create a list to hold the number of coins at each position
    max_position = 0
    for l, r, c in coins:
        max_position = max(max_position, r)

    coins_count = [0] * (max_position + 1)

    # Fill the coins_count array based on the input segments
    for l, r, c in coins:
        for i in range(l, r + 1):
            coins_count[i] += c

    # Now we find the maximum coins we can collect in any k consecutive bags
    max_coins = 0
    current_coins = sum(coins_count[1:k + 1])  # Initialize with the first k elements
    max_coins = current_coins

    for i in range(1, max_position - k + 2):  # Slide the window
        current_coins -= coins_count[i]  # Remove the leftmost element
        current_coins += coins_count[i + k - 1]  # Add the new rightmost element
        max_coins = max(max_coins, current_coins)

    return max_coins
```

**Root cause of failures:** The implementation has an off-by-one error in the sliding window logic. The initial window and sliding logic don't correctly handle all positions. Specifically, `current_coins = sum(coins_count[1:k+1])` starts at positions 1 to k, but then the sliding adds `coins_count[i+k-1]` which should be `coins_count[i+k]` to properly slide. This causes the implementation to miss optimal windows in some test cases.

## Root Cause

The algorithm incorrectly computes a running minimum from right to left. Looking at the expected outputs:

- `[5, 3, 4, 1, 3, 2]` → `[5, 3, 3, 1, 1, 1]`: Each position uses the minimum from its own position leftward through the array.
- `[100, 1, 50]` → `[100, 1, 1]`: Position 0 stays 100 (only itself), position 1 stays 1, position 2 becomes 1 (minimum from positions 0-2).

The correct algorithm should compute, for each position i, the minimum cost from position 0 to position i (inclusive), not from position i to the end.

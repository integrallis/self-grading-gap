## Implementation

```python
from typing import List

def minCosts(cost: List[int]) -> List[int]:
    n = len(cost)
    answer = [0] * n
    for i in range(n - 1, -1, -1):
        answer[i] = cost[i] if i == n - 1 else min(answer[i + 1], cost[i])
    return answer
```

```python
from typing import List

def maxSum(nums: List[int]) -> int:
    unique_nums = set()
    max_sum = float('-inf')
    current_sum = 0
    left = 0

    for right in range(len(nums)):
        while nums[right] in unique_nums:
            unique_nums.remove(nums[left])
            current_sum -= nums[left]
            left += 1
        unique_nums.add(nums[right])
        current_sum += nums[right]
        max_sum = max(max_sum, current_sum)

    return max_sum if max_sum != float('-inf') else 0
```

## Root Cause Summary

The algorithm is designed to find the maximum sum of a contiguous subarray with unique elements, but it never explores starting positions beyond where duplicates force it to move. In cases where the optimal solution excludes initial negative values or zeros, the window never resets to consider those better starting points.

## FIX DIRECTIVES:

FIX: In `hasMatch`, after finding a prefix match at position `i`, instead of checking `if s[i + len(prefix):].startswith(suffix)`, you need to search for the suffix anywhere in the remaining part of the string starting from position `i + len(prefix)`. The correct approach is: for each position `j` from `i + len(prefix)` onwards, check if the substring starting at `j` matches the suffix. If it does, and the total substring from `i` to `j + len(suffix)` fits within the string, return `True`. Specifically, use a nested loop: after `if s[i:i + len(prefix)] == prefix:`, iterate `for j in range(i + len(prefix), len(s) - len(suffix) + 1):` and check `if s[j:j + len(suffix)] == suffix: return True`.

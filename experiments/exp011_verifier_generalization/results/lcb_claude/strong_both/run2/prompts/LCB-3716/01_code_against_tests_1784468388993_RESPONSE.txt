## Root cause

The DP implementation has a fundamental flaw: it assumes that when computing dp[j], the previous element in the subsequence is nums[j-1]. However, dp[j] could represent a subsequence ending at j that doesn't include j-1 at all. The algorithm should track (position, last_difference) pairs, not just position.

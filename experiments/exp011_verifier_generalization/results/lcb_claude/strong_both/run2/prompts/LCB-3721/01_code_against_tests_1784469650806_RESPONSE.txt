## Root cause

The implementation fails to check if a token is "ALL" or "HERE" before treating it as an id-string. When processing a MESSAGE with mixed content like "id0 HERE", it splits the string and tries to parse each token as "idN", attempting `int("HERE"[2:])` which raises a ValueError.

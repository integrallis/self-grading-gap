```python
from typing import List


def maxFrequency(nums: List[int], k: int) -> int:
    n = len(nums)
    nums.sort()
    left = 0
    total = 0
    max_freq = 0

    for right in range(n):
        total += nums[right]
        while (nums[right] * (right - left + 1)) - total > k:
            total -= nums[left]
            left += 1
        max_freq = max(max_freq, right - left + 1)

    return max_freq
```

- **Current implementation:** Finds max-length contiguous subarray in the **sorted** array where all elements can be incremented to equal the rightmost (maximum) element with total cost ≤ k

The current implementation doesn't even use the parameter `k` as a target value — it treats `k` as a budget for element-wise increments.

## Root Cause

All failing tests share the same root cause: the current implementation simply sums all unique values from the input array in order. However, the problem requires:
1. Optionally delete some elements from the array
2. From the remaining array, select a **contiguous subarray** with all unique elements
3. Return the maximum possible sum

The implementation completely ignores the "contiguous subarray" constraint and the "maximum" optimization requirement.

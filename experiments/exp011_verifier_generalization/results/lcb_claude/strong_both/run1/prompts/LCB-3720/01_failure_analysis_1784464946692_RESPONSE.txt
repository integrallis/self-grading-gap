## Root Cause

The fundamental bug is in the **reachability check logic**. The current code:
1. Builds a `reachable` array by running DFS from each node
2. Checks `if not reachable[0]` to validate
3. This check is backwards: it verifies if node 0 was visited in some DFS, not if **all** nodes can reach node 0

The correct check should verify that every node i (where i > 0 or all i in range(n)) can reach node 0. Currently, it only checks if node 0 can reach itself.

Additionally, the binary search range needs to include the actual edge weights. The current range `[1, 10**6]` is arbitrary and may not include actual edge weights in the graph.

## Root Cause

All failing tests share the same root cause: **the reachability validation is inverted**. The implementation checks if node 0 is reachable from other nodes (via the accumulated `reachable` array), but the requirement is that **all non-zero nodes must be able to reach node 0**. The traversal should start from each node and check if it can reach node 0, not check if node 0 is in the visited set.

Full problem statement:

You are given an integer numberOfUsers representing the total number of users and an array events of size n x 3.
Each events[i] can be either of the following two types:

Message Event: ["MESSAGE", "timestamp_i", "mentions_string_i"]

This event indicates that a set of users was mentioned in a message at timestamp_i.
The mentions_string_i string can contain one of the following tokens:
		
id<number>: where <number> is an integer in range [0,numberOfUsers - 1]. There can be multiple ids separated by a single whitespace and may contain duplicates. This can mention even the offline users.
ALL: mentions all users.
HERE: mentions all online users.




Offline Event: ["OFFLINE", "timestamp_i", "id_i"]

This event indicates that the user id_i had become offline at timestamp_i for 60 time units. The user will automatically be online again at time timestamp_i + 60.



Return an array mentions where mentions[i] represents the number of mentions the user with id i has across all MESSAGE events.
All users are initially online, and if a user goes offline or comes back online, their status change is processed before handling any message event that occurs at the same timestamp.
Note that a user can be mentioned multiple times in a single message event, and each mention should be counted separately.
 
Example 1:

Input: numberOfUsers = 2, events = [["MESSAGE","10","id1 id0"],["OFFLINE","11","0"],["MESSAGE","71","HERE"]]
Output: [2,2]
Explanation:
Initially, all users are online.
At timestamp 10, id1 and id0 are mentioned. mentions = [1,1]
At timestamp 11, id0 goes offline.
At timestamp 71, id0 comes back online and "HERE" is mentioned. mentions = [2,2]

Example 2:

Input: numberOfUsers = 2, events = [["MESSAGE","10","id1 id0"],["OFFLINE","11","0"],["MESSAGE","12","ALL"]]
Output: [2,2]
Explanation:
Initially, all users are online.
At timestamp 10, id1 and id0 are mentioned. mentions = [1,1]
At timestamp 11, id0 goes offline.
At timestamp 12, "ALL" is mentioned. This includes offline users, so both id0 and id1 are mentioned. mentions = [2,2]

Example 3:

Input: numberOfUsers = 2, events = [["OFFLINE","10","0"],["MESSAGE","12","HERE"]]
Output: [0,1]
Explanation:
Initially, all users are online.
At timestamp 10, id0 goes offline.
At timestamp 12, "HERE" is mentioned. Because id0 is still offline, they will not be mentioned. mentions = [0,1]

 
Constraints:

1 <= numberOfUsers <= 100
1 <= events.length <= 100
events[i].length == 3
events[i][0] will be one of MESSAGE or OFFLINE.
1 <= int(events[i][1]) <= 10^5
The number of id<number> mentions in any "MESSAGE" event is between 1 and 100.
0 <= <number> <= numberOfUsers - 1
It is guaranteed that the user id referenced in the OFFLINE event is online at the time the event occurs.

def test_canonical_example_3():

    result = countMentions(2, [["OFFLINE", "10", "0"], ["MESSAGE", "12", "HERE"]])
    assert result == [0, 1]


def test_single_user_single_mention():
    # 1 user, message mentions id0 once -> [1]
    result = countMentions(1, [["MESSAGE", "5", "id0"]])
    assert result == [1]


def test_duplicate_mentions_in_same_message():
    # spec: "a user can be mentioned multiple times in a single message event, and each mention should be counted separately"
    # 2 users, id0 mentioned twice in same message -> [2, 0]
    result = countMentions(2, [["MESSAGE", "10", "id0 id0"]])
    assert result == [2, 0]


def test_all_mentions_all_users():
    # 3 users, "ALL" mentions all users -> [1, 1, 1]
    result = countMentions(3, [["MESSAGE", "10", "ALL"]])
    assert result == [1, 1, 1]


def test_here_mentions_only_online_users():
    # 3 users, id1 offline, "HERE" mentions only online users (id0, id2) -> [1, 0, 1]
    result = countMentions(3, [["OFFLINE", "10", "1"], ["MESSAGE", "20", "HERE"]])
    assert result == [1, 0, 1]


def test_user_comes_back_online_after_60_units():
    # User goes offline at 10, comes back at 70 (10+60)
    # "HERE" at timestamp 70 should include the user (status changes processed before message)
    result = countMentions(2, [["OFFLINE", "10", "0"], ["MESSAGE", "70", "HERE"]])
    assert result == [1, 1]


def test_user_still_offline_before_60_units():
    # User goes offline at 10, still offline at 69 (10+60=70)
    # "HERE" at timestamp 69 should not include the user
    result = countMentions(2, [["OFFLINE", "10", "0"], ["MESSAGE", "69", "HERE"]])
    assert result == [0, 1]


def test_multiple_offline_events():
    # Multiple users going offline at different times
    result = countMentions(3, [["OFFLINE", "10", "0"], ["OFFLINE", "20", "1"], ["MESSAGE", "30", "HERE"]])
    # At timestamp 30: id0 still offline (10+60=70), id1 still offline (20+60=80), only id2 online
    assert result == [0, 0, 1]


def test_mixed_id_and_special_mentions():
    # Message with specific ids and then "ALL"
    result = countMentions(3, [["MESSAGE", "10", "id0 id1"], ["MESSAGE", "20", "ALL"]])
    # First message: id0=1, id1=1, id2=0
    # Second message: all users +1 -> id0=2, id1=2, id2=1
    assert result == [2, 2, 1]


def test_no_mentions_for_user():
    # 3 users, only id0 and id1 mentioned
    result = countMentions(3, [["MESSAGE", "10", "id0 id1"]])
    assert result == [1, 1, 0]


def test_multiple_messages_same_timestamp():
    # Multiple MESSAGE events at same timestamp
    result = countMentions(2, [["MESSAGE", "10", "id0"], ["MESSAGE", "10", "id1"]])
    assert result == [1, 1]


def test_offline_and_message_same_timestamp():
    # spec: "if a user goes offline or comes back online, their status change is processed before handling any message event that occurs at the same timestamp"
    # User goes offline at timestamp 10, message at timestamp 10 with "HERE" should not include them
    result = countMentions(2, [["OFFLINE", "10", "0"], ["MESSAGE", "10", "HERE"]])
    assert result == [0, 1]


def test_user_comes_online_and_message_same_timestamp():
    # User goes offline at 10, comes back at 70 (10+60), message at 70 with "HERE" should include them
    result = countMentions(2, [["OFFLINE", "10", "0"], ["MESSAGE", "70", "HERE"]])
    assert result == [1, 1]


def test_all_includes_offline_users():
    # "ALL" mentions all users including offline ones
    result = countMentions(2, [["OFFLINE", "10", "0"], ["MESSAGE", "20", "ALL"]])
    assert result == [1, 1]


def test_many_users_all_online():
    # 5 users, all online, "HERE" mentions all
    result = countMentions(5, [["MESSAGE", "10", "HERE"]])
    assert result == [1, 1, 1, 1, 1]


def test_specific_ids_with_duplicates():
    # Multiple mentions of same ids in one message
    result = countMentions(3, [["MESSAGE", "10", "id0 id1 id0 id2 id1"]])
    # id0 mentioned twice, id1 mentioned twice, id2 mentioned once

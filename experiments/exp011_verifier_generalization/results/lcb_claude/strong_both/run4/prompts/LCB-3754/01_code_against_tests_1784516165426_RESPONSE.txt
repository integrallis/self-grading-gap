## Root cause

The implementation incorrectly assumes that with k changes available, you can simply add k to any position's distance. This doesn't account for the constraint that changes must be applied sequentially to the path and affect all subsequent positions. The algorithm treats k as a "free distance boost" rather than as modifications to the direction sequence that propagate through the remaining path.

## Root Cause
The `can_reach_zero` function performs BFS in the wrong direction. It checks reachability **from node 0 to other nodes**, but the problem requires checking if **all other nodes can reach node 0**. Since most test graphs have node 0 with no outgoing edges, the BFS from 0 cannot reach any other nodes, causing nearly all tests to fail.

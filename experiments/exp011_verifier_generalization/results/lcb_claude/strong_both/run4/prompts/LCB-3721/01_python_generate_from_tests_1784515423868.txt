Full problem statement:

You are given an integer numberOfUsers representing the total number of users and an array events of size n x 3.
Each events[i] can be either of the following two types:

Message Event: ["MESSAGE", "timestamp_i", "mentions_string_i"]

This event indicates that a set of users was mentioned in a message at timestamp_i.
The mentions_string_i string can contain one of the following tokens:
		
id<number>: where <number> is an integer in range [0,numberOfUsers - 1]. There can be multiple ids separated by a single whitespace and may contain duplicates. This can mention even the offline users.
ALL: mentions all users.
HERE: mentions all online users.




Offline Event: ["OFFLINE", "timestamp_i", "id_i"]

This event indicates that the user id_i had become offline at timestamp_i for 60 time units. The user will automatically be online again at time timestamp_i + 60.



Return an array mentions where mentions[i] represents the number of mentions the user with id i has across all MESSAGE events.
All users are initially online, and if a user goes offline or comes back online, their status change is processed before handling any message event that occurs at the same timestamp.
Note that a user can be mentioned multiple times in a single message event, and each mention should be counted separately.
 
Example 1:

Input: numberOfUsers = 2, events = [["MESSAGE","10","id1 id0"],["OFFLINE","11","0"],["MESSAGE","71","HERE"]]
Output: [2,2]
Explanation:
Initially, all users are online.
At timestamp 10, id1 and id0 are mentioned. mentions = [1,1]
At timestamp 11, id0 goes offline.
At timestamp 71, id0 comes back online and "HERE" is mentioned. mentions = [2,2]

Example 2:

Input: numberOfUsers = 2, events = [["MESSAGE","10","id1 id0"],["OFFLINE","11","0"],["MESSAGE","12","ALL"]]
Output: [2,2]
Explanation:
Initially, all users are online.
At timestamp 10, id1 and id0 are mentioned. mentions = [1,1]
At timestamp 11, id0 goes offline.
At timestamp 12, "ALL" is mentioned. This includes offline users, so both id0 and id1 are mentioned. mentions = [2,2]

Example 3:

Input: numberOfUsers = 2, events = [["OFFLINE","10","0"],["MESSAGE","12","HERE"]]
Output: [0,1]
Explanation:
Initially, all users are online.
At timestamp 10, id0 goes offline.
At timestamp 12, "HERE" is mentioned. Because id0 is still offline, they will not be mentioned. mentions = [0,1]

 
Constraints:

1 <= numberOfUsers <= 100
1 <= events.length <= 100
events[i].length == 3
events[i][0] will be one of MESSAGE or OFFLINE.
1 <= int(events[i][1]) <= 10^5
The number of id<number> mentions in any "MESSAGE" event is between 1 and 100.
0 <= <number> <= numberOfUsers - 1
It is guaranteed that the user id referenced in the OFFLINE event is online at the time the event occurs.

    # At timestamp 12: "ALL" mentions all users (including offline) -> mentions = [2, 2]
    assert countMentions(2, [["MESSAGE", "10", "id1 id0"], ["OFFLINE", "11", "0"], ["MESSAGE", "12", "ALL"]]) == [2, 2]


def test_canonical_example_3():
    # Example 3: numberOfUsers = 2, events = [["OFFLINE","10","0"],["MESSAGE","12","HERE"]]
    # At timestamp 10: id0 goes offline
    # At timestamp 12: "HERE" mentions only online users (id0 is offline, id1 is online) -> mentions = [0, 1]
    assert countMentions(2, [["OFFLINE", "10", "0"], ["MESSAGE", "12", "HERE"]]) == [0, 1]


def test_single_user_all_mention():
    # 1 user, MESSAGE with ALL -> mentions = [1]
    assert countMentions(1, [["MESSAGE", "5", "ALL"]]) == [1]


def test_single_user_here_mention():
    # 1 user online, MESSAGE with HERE -> mentions = [1]
    assert countMentions(1, [["MESSAGE", "5", "HERE"]]) == [1]


def test_single_user_id_mention():
    # 1 user, MESSAGE with id0 -> mentions = [1]
    assert countMentions(1, [["MESSAGE", "5", "id0"]]) == [1]


def test_multiple_id_mentions_same_message():
    # Duplicates count separately: id0 mentioned twice in one message -> mentions = [2]
    assert countMentions(1, [["MESSAGE", "5", "id0 id0"]]) == [2]


def test_user_offline_not_mentioned_by_here():
    # User offline at time of HERE mention is not counted
    # At timestamp 10: id0 goes offline (until 70)
    # At timestamp 20: HERE mentions only online users (id1) -> mentions = [0, 1]
    assert countMentions(2, [["OFFLINE", "10", "0"], ["MESSAGE", "20", "HERE"]]) == [0, 1]


def test_user_offline_mentioned_by_all():
    # User offline at time of ALL mention is still counted
    # At timestamp 10: id0 goes offline
    # At timestamp 20: ALL mentions all users -> mentions = [1, 1]
    assert countMentions(2, [["OFFLINE", "10", "0"], ["MESSAGE", "20", "ALL"]]) == [1, 1]


def test_user_offline_mentioned_by_id():
    # User offline can still be mentioned by id
    # At timestamp 10: id0 goes offline
    # At timestamp 20: id0 mentioned directly -> mentions = [1, 0]
    assert countMentions(2, [["OFFLINE", "10", "0"], ["MESSAGE", "20", "id0"]]) == [1, 0]


def test_user_comes_back_online_after_60_units():
    # User goes offline at timestamp 10, comes back at 70
    # At timestamp 70: HERE should include id0 (exactly at comeback time)
    # At timestamp 10: id0 goes offline
    # At timestamp 70: id0 is back online, HERE mentions both -> mentions = [1, 1]
    assert countMentions(2, [["OFFLINE", "10", "0"], ["MESSAGE", "70", "HERE"]]) == [1, 1]


def test_multiple_offline_events_different_users():
    # Multiple users can be offline
    # At timestamp 10: id0 goes offline
    # At timestamp 15: id1 goes offline
    # At timestamp 20: HERE mentions no one (all offline) -> mentions = [0, 0]
    assert countMentions(2, [["OFFLINE", "10", "0"], ["OFFLINE", "15", "1"], ["MESSAGE", "20", "HERE"]]) == [0, 0]


def test_no_mentions():
    # No MESSAGE events -> mentions = [0, 0, 0]
    assert countMentions(3, [["OFFLINE", "10", "0"]]) == [0, 0, 0]


def test_all_users_mentioned_multiple_times():
    # Three MESSAGE events with ALL, each user mentioned 3 times
    assert countMentions(2, [["MESSAGE", "10", "ALL"], ["MESSAGE", "20", "ALL"], ["MESSAGE", "30", "ALL"]]) == [3, 3]


def test_mixed_id_mentions():
    # Multiple specific id mentions across different messages
    # id0 mentioned in first message, id1 mentioned in second message
    assert countMentions(2, [["MESSAGE", "10", "id0"], ["MESSAGE", "20", "id1"]]) == [1, 1]


def test_here_with_all_online():
    # All users online, HERE mentions all
    assert countMentions(3, [["MESSAGE", "10", "HERE"]]) == [1, 1, 1]


def test_multiple_users_many_events():
    # Complex scenario with 3 users
    # At timestamp 5: id0, id1, id2 mentioned -> mentions = [1, 1, 1]
    # At timestamp 10: id1 goes offline
    # At timestamp 15: HERE mentions id0 and id2 (id1 offline) -> mentions = [2, 1, 2]
    # At timestamp 20: ALL mentions all -> mentions = [3, 2, 3]
    assert countMentions(3, [
        ["MESSAGE", "5", "id0 id1 id2"],
        ["OFFLINE", "10", "1"],
        ["MESSAGE", "15", "HERE"],
        ["MESSAGE", "20", "ALL"]
    ]) == [3, 2, 3]


def test_offline_and_message_same_timestamp():
    # Offline processed before message at same timestamp
    # At timestamp 10: id0 goes offline, then MESSAGE with HERE (id0 not mentioned)
    assert countMentions(2, [["OFFLINE", "10", "0"], ["MESSAGE", "10", "HERE"]]) == [0, 1]


def test_multiple_id_tokens_in_message():
    # Multiple different ids in one message
    # id0, id1, id2 each mentioned once
    assert countMentions(3, [["MESSAGE", "10", "id0 id1 id2"]]) == [1, 1, 1]


def test_duplicate_and_unique_ids_in_message():

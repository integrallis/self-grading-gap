## Implementation

```python
from typing import List

def maxAdjacentDistance(nums: List[int]) -> int:
    n = len(nums)
    max_diff = 0
    for i in range(n):
        # Calculate the absolute difference between adjacent elements
        diff = abs(nums[i] - nums[(i + 1) % n])
        max_diff = max(max_diff, diff)
    return max_diff

```

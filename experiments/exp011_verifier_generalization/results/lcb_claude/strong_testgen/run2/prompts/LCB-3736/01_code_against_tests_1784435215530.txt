## Implementation

```python
def findValidPair(s: str) -> str:
    from collections import Counter
    count = Counter(s)
    for i in range(len(s) - 1):
        if s[i] != s[i + 1]:
            first = int(s[i])
            second = int(s[i + 1])
            if count[s[i]] == first and count[s[i + 1]] == second:
                return s[i] + s[i + 1]
    return ""
```

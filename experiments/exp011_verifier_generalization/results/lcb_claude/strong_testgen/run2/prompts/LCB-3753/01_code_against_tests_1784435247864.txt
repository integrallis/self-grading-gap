## Implementation

```python
def maxDifference(s: str) -> int:
    from collections import Counter
    frequencies = Counter(s)
    max_odd = float('-inf')
    min_even = float('inf')
    for freq in frequencies.values():
        if freq % 2 == 1:
            max_odd = max(max_odd, freq)
        else:
            min_even = min(min_even, freq)
    return max_odd - min_even
```

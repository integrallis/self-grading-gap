Full problem statement:

You are given an m x n grid. A robot starts at the top-left corner of the grid (0, 0) and wants to reach the bottom-right corner (m - 1, n - 1). The robot can move either right or down at any point in time.
The grid contains a value coins[i][j] in each cell:

If coins[i][j] >= 0, the robot gains that many coins.
If coins[i][j] < 0, the robot encounters a robber, and the robber steals the absolute value of coins[i][j] coins.

The robot has a special ability to neutralize robbers in at most 2 cells on its path, preventing them from stealing coins in those cells.
Note: The robot's total coins can be negative.
Return the maximum profit the robot can gain on the route.
 
Example 1:

Input: coins = [[0,1,-1],[1,-2,3],[2,-3,4]]
Output: 8
Explanation:
An optimal path for maximum coins is:

Start at (0, 0) with 0 coins (total coins = 0).
Move to (0, 1), gaining 1 coin (total coins = 0 + 1 = 1).
Move to (1, 1), where there's a robber stealing 2 coins. The robot uses one neutralization here, avoiding the robbery (total coins = 1).
Move to (1, 2), gaining 3 coins (total coins = 1 + 3 = 4).
Move to (2, 2), gaining 4 coins (total coins = 4 + 4 = 8).


Example 2:

Input: coins = [[10,10,10],[10,10,10]]
Output: 40
Explanation:
An optimal path for maximum coins is:

Start at (0, 0) with 10 coins (total coins = 10).
Move to (0, 1), gaining 10 coins (total coins = 10 + 10 = 20).
Move to (0, 2), gaining another 10 coins (total coins = 20 + 10 = 30).
Move to (1, 2), gaining the final 10 coins (total coins = 30 + 10 = 40).


 
Constraints:

m == coins.length
n == coins[i].length
1 <= m, n <= 500
-1000 <= coins[i][j] <= 1000

    # 1x4 grid with negative values
    # Path: (0,0)->(0,1)->(0,2)->(0,3)
    # Without neutralization: 1 + (-5) + (-3) + 2 = -5
    # Neutralize the two negative cells: 1 + 0 + 0 + 2 = 3
    assert maximumAmount([[1, -5, -3, 2]]) == 3


def test_single_column_with_negative():
    # 4x1 grid with negative values
    # Path: (0,0)->(1,0)->(2,0)->(3,0)
    # Without neutralization: 3 + (-2) + (-4) + 5 = 2
    # Neutralize the two negative cells: 3 + 0 + 0 + 5 = 8
    assert maximumAmount([[3], [-2], [-4], [5]]) == 8


def test_all_negative_values():
    # 2x2 grid with all negative values
    # Path must be chosen, neutralize up to 2 worst cells
    # Possible paths: 
    # (0,0)->(0,1)->(1,1): -1 + (-2) + (-4) = -7, neutralize -4 and -2: -1
    # (0,0)->(1,0)->(1,1): -1 + (-3) + (-4) = -8, neutralize -4 and -3: -1
    assert maximumAmount([[-1, -2], [-3, -4]]) == -1


def test_all_positive_values():
    # 2x2 grid with all positive values
    # No neutralization needed
    # Best path: (0,0)->(0,1)->(1,1) or (0,0)->(1,0)->(1,1)
    # Both give: 5 + 10 + 15 = 30 or 5 + 8 + 15 = 28
    assert maximumAmount([[5, 10], [8, 15]]) == 30

    # Path with 3 negative cells, can only neutralize 2
    # 1x4 grid: (0,0)->(0,1)->(0,2)->(0,3)
    # Values: 10 + (-20) + (-15) + (-10)
    # Neutralize -20 and -15: 10 + 0 + 0 + (-10) = 0
    assert maximumAmount([[10, -20, -15, -10]]) == 0


def test_neutralize_only_negative_cells():
    # Ensure neutralization is only beneficial for negative cells
    # 1x3 grid: all positive, no neutralization needed
    assert maximumAmount([[5, 10, 15]]) == 30


def test_mixed_values_small_grid():
    # 2x3 grid with mixed positive and negative values
    # Multiple paths possible, find optimal with up to 2 neutralizations
    coins = [[1, -2, 3], [4, 5, -6]]
    # Best path might be (0,0)->(0,1)->(0,2)->(1,2)
    # Without neutralization: 1 + (-2) + 3 + (-6) = -4
    # Neutralize -2 and -6: 1 + 0 + 3 + 0 = 4
    # Or (0,0)->(1,0)->(1,1)->(1,2)
    # Without neutralization: 1 + 4 + 5 + (-6) = 4
    # Neutralize -6: 1 + 4 + 5 + 0 = 10
    assert maximumAmount(coins) == 10


def test_large_negative_value():
    # 2x2 grid with one very large negative value
    # Robot should neutralize the large negative
    coins = [[100, 50], [75, -1000]]
    # Path (0,0)->(0,1)->(1,1): 100 + 50 + (-1000) = -850
    # Neutralize -1000: 100 + 50 + 0 = 150
    # Path (0,0)->(1,0)->(1,1): 100 + 75 + (-1000) = -825
    # Neutralize -1000: 100 + 75 + 0 = 175
    assert maximumAmount(coins) == 175


def test_no_negative_values_neutralization_unused():
    # 3x3 grid with no negative values
    # Neutralization ability is not needed
    coins = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]
    # Best path: (0,0)->(0,1)->(0,2)->(1,2)->(2,2)
    # Coins: 1 + 2 + 3 + 6 + 9 = 21
    assert maximumAmount(coins) == 21


def test_zero_values():
    # Grid with zero values mixed with positive and negative

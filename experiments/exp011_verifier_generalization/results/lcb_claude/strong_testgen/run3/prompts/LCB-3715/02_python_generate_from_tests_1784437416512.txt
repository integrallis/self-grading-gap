There are an infinite amount of bags on a number line, one bag for each coordinate. Some of these bags contain coins.
You are given a 2D array coins, where coins[i] = [l_i, r_i, c_i] denotes that every bag from l_i to r_i contains c_i coins.

Return the maximum amount of coins you can obtain by collecting k consecutive bags.

Example 2:

Output: 6
Explanation:
Selecting bags at positions [1, 2] gives the maximum number of coins: 3 + 3 = 6.

 
Constraints:

1 <= k <= 10^9
coins[i] == [l_i, r_i, c_i]
1 <= l_i <= r_i <= 10^9
1 <= c_i <= 1000

```python
from typing import List
```


```python
def maximumCoins(coins: List[List[int]], k: int) -> int:
    # Create a dictionary to hold the number of coins at each position
    coin_map = {}
    
    # Fill the coin_map with the total coins in their respective ranges
    for l, r, c in coins:
        for pos in range(l, r + 1):
            if pos in coin_map:
                coin_map[pos] += c
            else:
                coin_map[pos] = c
    
    # Create a sorted list of the positions that have coins
    positions = sorted(coin_map.keys())
    max_coins = 0
    n = len(positions)
    
    # Iterate through each position and calculate the maximum coins for k bags
    for i in range(n):
        # Calculate the start and end of the window
        start_pos = positions[i]
        end_pos = start_pos + k - 1
        coins_in_window = 0
        
        # Calculate the total coins in the current window
        for j in range(i, n):
            if positions[j] > end_pos:
                break
            coins_in_window += coin_map[positions[j]]
        
        max_coins = max(max_coins, coins_in_window)
    
    return max_coins
```

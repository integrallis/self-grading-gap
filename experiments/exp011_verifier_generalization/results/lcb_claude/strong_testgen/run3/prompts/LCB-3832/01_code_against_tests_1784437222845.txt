## Implementation

```python
from typing import List

def minCosts(cost: List[int]) -> List[int]:
    n = len(cost)
    answer = [0] * n
    for i in range(n):
        answer[i] = cost[i] if i == 0 else min(cost[i], answer[i - 1])
        if i > 0:
            answer[i] = min(answer[i], answer[i - 1])
    return answer
```

## Implementation

```python
from typing import List

def maxAdjacentDistance(nums: List[int]) -> int:
    max_distance = 0
    n = len(nums)
    for i in range(n):
        # Calculate the distance between adjacent elements, considering the circular nature
        distance = abs(nums[i] - nums[(i + 1) % n])
        max_distance = max(max_distance, distance)
    return max_distance
```

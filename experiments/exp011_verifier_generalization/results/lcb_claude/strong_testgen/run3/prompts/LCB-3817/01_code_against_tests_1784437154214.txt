## Implementation

```python
def maxContainers(n: int, w: int, maxWeight: int) -> int:
    # Total number of cells in the n x n deck
    total_cells = n * n
    # Maximum containers that can be loaded based on weight
    max_by_weight = maxWeight // w
    # Return the minimum of total cells and max containers by weight
    return min(total_cells, max_by_weight)
```

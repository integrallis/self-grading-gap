## Implementation

```python
def reverseDegree(s: str) -> int:
    reverse_alphabet_position = lambda c: 27 - (ord(c) - ord('a'))
    return sum(reverse_alphabet_position(c) * (i + 1) for i, c in enumerate(s))
```

## Implementation

```python
def maxDifference(s: str) -> int:
    from collections import Counter
    frequencies = Counter(s)
    max_odd = float('-inf')
    min_even = float('inf')

    for count in frequencies.values():
        if count % 2 == 0:
            min_even = min(min_even, count)
        else:
            max_odd = max(max_odd, count)

    return max_odd - min_even
```

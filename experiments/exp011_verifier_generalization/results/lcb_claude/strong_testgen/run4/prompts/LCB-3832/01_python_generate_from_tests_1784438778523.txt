Full problem statement:

You are given an integer array cost of size n. You are currently at position n (at the end of the line) in a line of n + 1 people (numbered from 0 to n).
You wish to move forward in the line, but each person in front of you charges a specific amount to swap places. The cost to swap with person i is given by cost[i].
You are allowed to swap places with people as follows:

If they are in front of you, you must pay them cost[i] to swap with them.
If they are behind you, they can swap with you for free.

Return an array answer of size n, where answer[i] is the minimum total cost to reach each position i in the line.
 
Example 1:

Input: cost = [5,3,4,1,3,2]
Output: [5,3,3,1,1,1]
Explanation:
We can get to each position in the following way:

i = 0. We can swap with person 0 for a cost of 5.
i = 1. We can swap with person 1 for a cost of 3.
i = 2. We can swap with person 1 for a cost of 3, then swap with person 2 for free.
i = 3. We can swap with person 3 for a cost of 1.
i = 4. We can swap with person 3 for a cost of 1, then swap with person 4 for free.
i = 5. We can swap with person 3 for a cost of 1, then swap with person 5 for free.


Example 2:

Input: cost = [1,2,4,6,7]
Output: [1,1,1,1,1]
Explanation:
We can swap with person 0 for a cost of 1, then we will be able to reach any position i for free.

 
Constraints:

1 <= n == cost.length <= 100
1 <= cost[i] <= 100

def test_canonical_example_1():

def test_canonical_example_2():
    # spec: cost = [1,2,4,6,7] -> [1,1,1,1,1]
    assert minCosts([1, 2, 4, 6, 7]) == [1, 1, 1, 1, 1]


def test_single_element():
    # n=1: only one person (position 0), we start at position 1
    # to reach position 0, we must swap with person 0, paying cost[0]
    assert minCosts([5]) == [5]


def test_all_same_cost():
    # cost = [3,3,3]: 
    # pos 0: pay 3 to swap with person 0
    # pos 1: pay 3 to swap with person 1
    # pos 2: pay 3 to swap with person 0, then free swap with person 2
    #        OR pay 3 to swap with person 1, then free swap with person 2
    #        minimum is 3
    assert minCosts([3, 3, 3]) == [3, 3, 3]


def test_decreasing_costs():
    # cost = [5,4,3,2,1]:
    # pos 0: pay 5 to swap with person 0
    # pos 1: pay 4 to swap with person 1
    # pos 2: pay 3 to swap with person 2
    # pos 3: pay 2 to swap with person 3
    # pos 4: pay 1 to swap with person 4
    assert minCosts([5, 4, 3, 2, 1]) == [5, 4, 3, 2, 1]


def test_increasing_costs():
    # cost = [1,2,3,4,5]:
    # pos 0: pay 1 to swap with person 0
    # pos 1: pay 1 to swap with person 0, then free swap with person 1 -> cost 1
    # pos 2: pay 1 to swap with person 0, then free swap with person 2 -> cost 1
    # pos 3: pay 1 to swap with person 0, then free swap with person 3 -> cost 1
    # pos 4: pay 1 to swap with person 0, then free swap with person 4 -> cost 1
    assert minCosts([1, 2, 3, 4, 5]) == [1, 1, 1, 1, 1]


def test_two_elements():
    # cost = [10, 5]:
    # pos 0: pay 10 to swap with person 0
    # pos 1: pay 5 to swap with person 1
    assert minCosts([10, 5]) == [10, 5]


def test_two_elements_reverse():
    # cost = [5, 10]:
    # pos 0: pay 5 to swap with person 0
    # pos 1: pay 5 to swap with person 0, then free swap with person 1 -> cost 5
    assert minCosts([5, 10]) == [5, 5]


def test_middle_minimum():
    # cost = [10, 10, 1, 10, 10]:
    # pos 0: pay 10 to swap with person 0
    # pos 1: pay 10 to swap with person 1
    # pos 2: pay 1 to swap with person 2
    # pos 3: pay 1 to swap with person 2, then free swap with person 3 -> cost 1
    # pos 4: pay 1 to swap with person 2, then free swap with person 4 -> cost 1
    assert minCosts([10, 10, 1, 10, 10]) == [10, 10, 1, 1, 1]

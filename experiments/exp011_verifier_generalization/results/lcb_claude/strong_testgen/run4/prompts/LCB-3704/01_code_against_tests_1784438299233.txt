## Implementation

```python
from typing import List

def countPartitions(nums: List[int]) -> int:
    total_sum = sum(nums)
    count = 0
    left_sum = 0
    for i in range(len(nums) - 1):  # We don't consider the last index for partition
        left_sum += nums[i]
        right_sum = total_sum - left_sum
        if (left_sum - right_sum) % 2 == 0:
            count += 1
    return count

```
